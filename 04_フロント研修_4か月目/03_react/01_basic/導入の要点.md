### Reactとは？
まず一言で
> Reactは、画面をコンポーネントという部品の組み合わせで作るライブラリです。

画面

├─ Header
├─ Menu
├─ UserList
│   ├─ UserCard
│   ├─ UserCard
│   └─ UserCard
└─ Footer


### なぜ部品にするのか
例えばボタンが100個ある画面なら、JavaScriptやHTMLだけだと同じようなコードを書きがちです。

Reactでは
```typescript
<Button />
<Button />
<Button />
```

のように部品を何度でも使えます。

つまり、**再利用できる**、**修正箇所が一か所になる**、**役割ごとにファイルを分けられる**というメリットがあります。

### コンポーネントとは？
**JavaScript(TypeScript)の関数**です。

```typescript
function Button() {
  return <button>登録</button>;
}
```
ただ、、、
> 関数だけど、値ではなく画面(JSX)を返す関数

です。
### JSXとは？

「HTMLっぽいですが、HTMLではありません。」
下記の特徴
- JavaScriptの中にHTML風の構文を書ける（厳密には違います）
- 最終的にはJavaScriptに変換される（実行時にはjsに変換されます）
### Props
「部品は固定だと意味がありません。」

同じUserCardでも

```
UserCard
名前：田中

UserCard
名前：佐藤

UserCard
名前：鈴木
```

と表示したいので、コンポーネントにデータを渡す仕組みがPropsです。
```typescript
<UserCard name="田中" />
<UserCard name="佐藤" />
<UserCard name="鈴木" />
```

> Propsは関数の引数と同じようなもの

```typescript
greet("田中");
```
と
```typescript
<UserCard name="田中" />
```
はどちらも「値を渡している」という点では同じ考え方です。
