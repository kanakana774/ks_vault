「レスポンシブデザイン」と、その最新進化系である「コンテナクエリ」について解説します。

これまでは「ブラウザの画面幅（ビューポート）」に合わせて画面全体を調整してきましたが、現代の設計では**「部品（コンポーネント）が置かれた場所の幅」**に合わせて形を変える手法が主流になりつつあります。

---

### 1. レスポンシブの基本：メディアクエリ（Media Queries）

メディアクエリは、**「画面（画面全体）の幅」**を条件にしてスタイルを切り替える仕組みです。

#### 【アンチパターン】PCから先に作り、`max-width` でスマホ版を作る
PCデザインを無理やりスマホに詰め込む形になり、CSSが複雑になりがちです。

#### 【ベストプラクティス】「モバイルファースト」で作り、`min-width` で拡張する
まずはスマホ用のシンプルな1カラムを「素」の状態で書き、画面が広くなったら要素を横に並べるという足し算の設計です。コードが非常にスッキリします。

```html
<div class="responsive-layout">
  <aside class="sidebar">SIDEBAR</aside>
  <main class="main-content">MAIN CONTENT</main>
</div>

<style>
  /* 1. まずはスマホ用（基本スタイル） */
  .responsive-layout {
    display: flex;
    flex-direction: column; /* 縦並び */
    gap: 10px;
  }
  .sidebar, .main-content {
    padding: 20px;
    background: #ddd;
  }

  /* 2. 画面が 768px 以上になったらPC用に拡張 */
  @media (min-width: 768px) {
    .responsive-layout {
      flex-direction: row; /* 横並びにする */
    }
    .sidebar {
      flex: 1; /* 1:3の比率で分ける */
    }
    .main-content {
      flex: 3;
    }
  }
</style>
```

### 2. 現代の革命：コンテナクエリ（Container Queries）

メディアクエリの弱点は、**「その部品がどこに置かれても、画面幅にしか反応できない」**点でした。
たとえば「お知らせカード」という部品が、「広いメインエリア」にある時と「狭いサイドバー」にある時で形を変えたい場合、画面幅（メディアクエリ）では対応しきれません。

これを解決するのが**コンテナクエリ**です。

#### 【実践：置かれた場所で形を変える「賢いカード」】

**HTML:**
```html
<div class="page">
  <!-- ケース1: 広いメインエリアにあるカード -->
  <section class="main-area">
    <div class="card-container">
      <article class="smart-card">
        <div class="photo">IMAGE</div>
        <div class="info">広い場所では横並びになります</div>
      </article>
    </div>
  </section>

  <!-- ケース2: 狭いサイドバーにあるカード -->
  <aside class="sidebar-area">
    <div class="card-container">
      <article class="smart-card">
        <div class="photo">IMAGE</div>
        <div class="info">狭い場所では自動で縦並びになります</div>
      </article>
    </div>
  </aside>
</div>
```

**CSS:**
```css
/* 1. 親要素を「コンテナ」として登録する */
.card-container {
  container-type: inline-size; /* 横幅を監視対象にする */
  width: 100%;
  margin-bottom: 20px;
}

/* 2. 基本スタイル（狭い時＝縦並び） */
.smart-card {
  display: flex;
  flex-direction: column;
  gap: 10px;
  padding: 10px;
  background: white;
  border: 1px solid #ccc;
}
.photo { background: #333; color: white; height: 100px; }

/* 3. コンテナ（親）が 400px 以上になった時だけスタイル変更 */
@container (min-width: 400px) {
  .smart-card {
    flex-direction: row; /* 横並びにする */
    align-items: center;
  }
  .photo { width: 150px; height: 100px; flex-shrink: 0; }
}

/* デモ用のレイアウト調整（PCで見ると左右に分かれる） */
.page { display: flex; gap: 20px; padding: 20px; }
.main-area { flex: 2; }
.sidebar-area { flex: 1; border-left: 2px dashed #ccc; padding-left: 20px; }
```

*   **違いの観点：** メディアクエリを使っていません。そのため、画面幅が同じでも、**「置かれた場所が狭ければ縦、広ければ横」**という、真に再利用可能なコンポーネントが作れます。

### 3. 初期から癖付けるべき「レスポンシブ」の設計思想

1.  **「絶対値 (px)」を捨て、「相対値 (%) / Flex / Grid」で逃げる**
    *   メディアクエリを書く前に、Flexboxの `flex-wrap` や Gridの `auto-fit` で解決できないか考えましょう。メディアクエリは「最後の手段」にするのが最も壊れにくい設計です。
2.  **ブレイクポイント（切り替える幅）を細かく作りすぎない**
    *   スマホ・タブレット・PCの3段階程度に留めましょう。基本は `768px` と `1024px` あたりが一般的です。
3.  **画像には必ず `max-width: 100%;` を指定する**
    *   画像が親要素を突き抜けるのを防ぐ、レスポンシブの「おまじない」です。

---

### まとめ：レスポンシブの使い分けガイド

| 技術 | 監視対象 | 使いどころ |
| :--- | :--- | :--- |
| **Flexbox / Grid** | コンテンツ | メディアクエリなしで、入り切らないものを自動で改行・調整したいとき。 |
| **メディアクエリ** | ブラウザ画面全体 | ヘッダーのメニューを「ハンバーガーメニュー」に切り替えるなど、画面全体の構成を変えるとき。 |
| **コンテナクエリ** | 直近の親要素 | どこに置いても最適な形になる「自律した部品（カードやボタン）」を作るとき。 |

### 最終的な実行可能サンプル：現代のハイブリッド設計

「モバイルファースト」と「コンテナクエリ」を組み合わせた、理想的な構造のデモです。

```html
<div class="layout-wrapper">
  <!-- コンテナとして機能する親 -->
  <div class="component-box">
    <div class="news-card">
      <div class="badge">New</div>
      <div class="text">画面幅ではなく、このグレーの枠の幅に反応して、450pxを超えると色と配置が変わります。</div>
    </div>
  </div>
</div>

<style>
  /* 1. モバイルファーストの基本 */
  .layout-wrapper {
    padding: 20px;
    background: #f0f0f0;
  }

  /* 2. コンテナの設定 */
  .component-box {
    container-type: inline-size;
    width: 100%;
    /* PCで見ている場合、ここをマウスで広げたり狭めたりできれば変化がわかります */
    max-width: 800px;
    margin: 0 auto;
    border: 3px solid #ccc;
    background: #fff;
  }

  /* 3. カードの基本（狭い時） */
  .news-card {
    padding: 1rem;
    display: flex;
    flex-direction: column;
    gap: 10px;
  }
  .badge {
    background: red; color: white; width: fit-content; padding: 2px 8px;
  }

  /* 4. コンテナクエリで拡張 */
  @container (min-width: 450px) {
    .news-card {
      flex-direction: row;
      background: #e3f2fd;
      align-items: center;
    }
    .badge {
      background: blue;
    }
  }
</style>
```

これで、現代のCSSにおいて最も重要なトピックを一通りカバーしました。
これまでの「ボックスモデル」「Flex/Grid」「変数」「レスポンシブ」が組み合わさることで、美しく保守しやすいCSSが書けるようになります。
