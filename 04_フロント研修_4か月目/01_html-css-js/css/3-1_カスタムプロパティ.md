「CSS変数（カスタムプロパティ）」は、現代のCSS設計において**「最も革命的」**と言っても過言ではない機能です。

これを使えるようになると、色や余白の管理が一箇所で済むようになり、修正作業が劇的に楽になります。また、「ダークモード」などの複雑な実装も驚くほどシンプルに実現できます。

---

### 1. 基本：変数の定義と呼び出し

変数は `--`（ハイフン2つ）から始まる名前で定義し、`var()` 関数で呼び出します。

#### 【基本：どこでも使える変数（グローバル変数）】
通常、すべての要素から参照できるように `:root`（html要素のこと）に定義します。

```html
<div class="box">
  CSS変数はとても便利です
</div>

<style>
  /* 1. 定義する（プロジェクトの共通ルールとして） */
  :root {
    --main-color: #3498db;
    --spacing-base: 1.5rem;
    --border-radius: 8px;
  }

  /* 2. 使う */
  .box {
    background-color: var(--main-color);
    padding: var(--spacing-base);
    border-radius: var(--border-radius);
    color: white;
  }
</style>
```

---

### 2. アンチパターン vs ベストプラクティス：色の管理

#### 【アンチパターン】直接値を書き込む（ハードコーディング）
色の変更が必要になった際、CSS全体を検索して何十箇所も書き換える必要があります。ミスも起きやすく、管理が崩壊します。

#### 【ベストプラクティス】セマンティック（意味のある）命名で管理する
単に `--blue: #0000ff;` とするのではなく、**「その色が何に使われるか」**という名前（`--primary-color` など）を付けます。

```html
<div class="card-bad">アンチパターンのカード</div>
<div class="card-good">ベストプラクティスのカード</div>

<style>
  :root {
    /* 意味に基づいた命名（Semantic Naming） */
    --brand-primary: #ff5722;
    --text-main: #333333;
    --bg-light: #f5f5f5;
  }

  /* アンチパターン：直接指定 */
  .card-bad {
    background-color: #f5f5f5; /* 後で「少しグレーに」と言われたら全部直すの？ */
    color: #333333;
    border-left: 5px solid #ff5722;
  }

  /* ベストプラクティス：変数指定 */
  .card-good {
    background-color: var(--bg-light);
    color: var(--text-main);
    border-left: 5px solid var(--brand-primary);
  }

  /* 共通の見た目 */
  .card-bad, .card-good { padding: 15px; margin-bottom: 10px; }
</style>
```

### 3. 応用：ダークモードへの対応

CSS変数の真価は、**「値の中身を動的に入れ替えられる」**ことにあります。メディアクエリの中で変数の「値」だけを書き換えれば、HTML側を一切いじることなくダークモードが完成します。

```html
<div class="theme-box">
  <h2>テーマ切り替えのデモ</h2>
  <p>OSの設定をダークモードにすると、色が変わります。</p>
</div>

<style>
  /* ライトモード（デフォルト） */
  :root {
    --bg-color: #ffffff;
    --text-color: #222222;
    --accent: #007bff;
  }

  /* ダークモードの設定（OSの設定を検知） */
  @media (prefers-color-scheme: dark) {
    :root {
      --bg-color: #1a1a1a;
      --text-color: #f0f0f0;
      --accent: #ffcc00;
    }
  }

  .theme-box {
    background-color: var(--bg-color);
    color: var(--text-color);
    border: 2px solid var(--accent);
    padding: 2rem;
    transition: all 0.3s ease; /* 切り替えをスムーズに */
  }
</style>
```

### 4. ローカルスコープ：特定の場所だけ上書きする

変数は「近い場所で定義されたもの」が優先されます。これを利用すると、共通のコンポーネントを一部分だけカスタマイズするのが非常に簡単になります。

#### 【例：色違いのボタンを作る】

```html
<button class="custom-btn">標準ボタン</button>
<button class="custom-btn danger">危険ボタン</button>
<button class="custom-btn success">成功ボタン</button>

<style>
  .custom-btn {
    /* ボタン内だけで有効な変数を定義 */
    --btn-bg: #eeeeee;
    --btn-text: #333333;

    background-color: var(--btn-bg);
    color: var(--btn-text);
    padding: 10px 20px;
    border: none;
    margin: 5px;
  }

  /* クラスに応じて「中身」だけを書き換える */
  .danger {
    --btn-bg: #d32f2f;
    --btn-text: #ffffff;
  }

  .success {
    --btn-bg: #388e3c;
    --btn-text: #ffffff;
  }
</style>
```

*   **違いの観点：** これまでは `.danger { background-color: ...; color: ...; }` とプロパティを何個も書き直していましたが、**「変数の値だけ変える」**という手法ならコードが極めてスッキリします。

### 5. 現代の設計・整理術：CSS変数の活用ルール

1.  **「マジックナンバー（謎の数値）」を撲滅する**
    *   `margin: 17px;` のような「なんとなく決めた数値」は使わず、`--space-m: 16px;` のような共通変数を使う癖をつけましょう。
2.  **計算（calc）と組み合わせる**
    *   `width: calc(100% - var(--sidebar-width));` のように書けば、サイドバーの幅が変わってもメインコンテンツの計算が自動で追従します。
3.  **大文字ではなく小文字＋ハイフンで書く**
    *   CSSの慣習として `--MainColor` よりも `--main-color` が一般的です。
4.  **フォールバック（予備）を設定する**
    *   `var(--my-color, black)` と書くと、もし `--my-color` が未定義だった場合に `black` が採用されます。大規模開発での安全策になります。

### まとめ：CSS変数 実行可能サンプル

「デザインシステム」のミニチュア版です。

```html
<div class="design-system-demo">
  <header class="ds-header">Design System</header>
  <div class="ds-content">
    <p>変数を一箇所変えるだけで、サイト全体の雰囲気が変わります。</p>
    <div class="ds-grid">
      <div class="ds-card">Card 1</div>
      <div class="ds-card highlight">Card 2</div>
      <div class="ds-card">Card 3</div>
    </div>
  </div>
</div>

<style>
  :root {
    /* 1. トークンの定義（ここで全ルールを決める） */
    --sys-bg: #fdfdfd;
    --sys-primary: #6200ee;
    --sys-surface: #ffffff;
    --sys-on-surface: #333;
    --sys-gap: 1rem;
    --sys-radius: 12px;
    --sys-shadow: 0 4px 6px rgba(0,0,0,0.1);
  }

  .design-system-demo {
    background-color: var(--sys-bg);
    font-family: sans-serif;
    padding: var(--sys-gap);
  }

  .ds-header {
    background-color: var(--sys-primary);
    color: white;
    padding: 1rem;
    border-radius: var(--sys-radius);
    margin-bottom: var(--sys-gap);
  }

  .ds-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
    gap: var(--sys-gap);
  }

  .ds-card {
    background-color: var(--sys-surface);
    color: var(--sys-on-surface);
    padding: 2rem;
    border-radius: var(--sys-radius);
    box-shadow: var(--sys-shadow);
    text-align: center;
  }

  /* 2. 部分的なカスタマイズも変数を変えるだけ */
  .ds-card.highlight {
    --sys-surface: #fff9c4; /* このカードだけ背景を黄色に */
    border: 2px solid var(--sys-primary);
  }
</style>
```
