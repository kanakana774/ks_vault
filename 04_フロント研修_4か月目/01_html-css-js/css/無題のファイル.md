結論から言うと、**現代のレイアウト（横並びや整列）において、Flexbox（およびGrid）を使うのが「正解」であり「標準」です。**

しかし、古いソースコードの修正や、なぜFlexboxが便利なのかを深く理解するために、**「原始的な手法」と「displayの基本ルール」**を知っておくことは非常に重要です。

---

### 1. 根本ルール：Block（ブロック） vs Inline（インライン）

Flexboxが登場する前のCSSは、この2つの性質の組み合わせだけでレイアウトを作っていました。

| 特徴 | ブロック要素 (`div`, `h1`, `p`) | インライン要素 (`span`, `a`, `strong`) |
| :--- | :--- | :--- |
| **並び方** | **縦に積まれる**（改行される） | **横に流れる**（改行されない） |
| **幅・高さ** | **指定できる**（デフォルト100%） | **指定できない**（中身のサイズのみ） |
| **余白 (Margin/Padding)** | **上下左右すべて効く** | **左右は効くが、上下は無効**（正確には背景などは広がるが、他の要素を押し退けない） |

#### 【重要】インライン要素にサイズを指定したいとき
「横に並べたいけど、幅や高さも指定したい」というときは、**`display: inline-block;`** を使います。これがFlexbox以前の「横並び」の定番でした。

---

### 2. 原始的な「横並び」手法（比較用）

Flexbox以前、エンジニアが苦労して使っていた3つの手法を比較します。

#### ① Float（フロート）手法
本来「画像の周りに文字を回り込ませる」ための機能を、無理やりレイアウトに使っていました。

*   **HTML:**
```html
    <div class="clearfix">
      <div class="left">左</div>
      <div class="right">右</div>
    </div>
```
*   **CSS:**
```css
    .left { float: left; width: 50%; }
    .right { float: right; width: 50%; }
    /* 親要素の高さが消えるため、「clearfix」というおまじないが必須 */
    .clearfix::after {
      content: "";
      display: block;
      clear: both;
    }
```
*   **現代の視点:** **「負の遺産」です。** 縦方向の中央揃えが不可能に近く、管理が非常に面倒です。

#### ② Inline-block 手法
要素をテキストのように横に並べる手法です。

*   **CSS:**
```css
    .item {
      display: inline-block;
      width: 30%;
      vertical-align: top; /* 縦の位置を合わせるのに必要 */
    }
```
*   **弱点:** HTML上の改行が「半角スペース」として表示されてしまい、隙間ができてしまうという有名なバグ（隙間問題）があります。

#### ③ Table-cell 手法
要素を「表のセル」として扱わせる手法です。

*   **CSS:**
```css
    .container { display: table; width: 100%; }
    .item { display: table-cell; }
```
*   **利点:** 昔の手法の中では唯一「高さが自動で揃う」という特徴がありましたが、柔軟性に欠けました。

---

### 3. なぜ Flexbox が「正解」なのか（比較まとめ）

「上下左右の中央揃え」を例に、原始的な方法とFlexboxを比較します。

#### 【例：親要素の中で、子要素を完全に中央に置きたい】

**A. 原始的な方法（Positioning）**
```css
.parent { position: relative; height: 300px; }
.child {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%); /* これで微調整が必要 */
}
```
*   **問題:** 子要素のサイズが確定していないと計算が狂ったり、コードが複雑。

**B. 現代の方法（Flexbox）**
```css
.parent {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 300px;
}
```
*   **メリット:** 子要素のサイズに関わらず、たったこれだけで完璧に中央へ。圧倒的にシンプルです。

### 4. まとめ表：何が効いて、何が効かないのか？

ここを癖付けて覚えると、CSSの「なぜか動かない」が激減します。

| 指定したいプロパティ | `inline` | `block` | `inline-block` | `flex` (子要素) |
| :--- | :---: | :---: | :---: | :---: |
| `width` / `height` | **× 効かない** | **○ 効く** | **○ 効く** | **○ 効く** |
| `margin-top` / `bottom` | **× 効かない** | **○ 効く** | **○ 効く** | **○ 効く** |
| `padding-top` / `bottom` | **△ 見た目だけ** | **○ 効く** | **○ 効く** | **○ 効く** |
| `vertical-align` | **○ 効く** | **× 効かない** | **○ 効く** | **× (align-itemsを使う)** |
| `text-align: center` | **○ (親に書く)** | **× 効かない** | **○ (親に書く)** | **× (justify-を使う)** |

---

### 結論：初心者が持つべき方針

1.  **「横並び」と言われたら、まずは `display: flex;` を考える。**
    *   `float` は忘れてOKです。
2.  **文章の中の一部（リンクや強調など）にだけ色をつけたいなら `inline`。**
    *   この時、幅や高さを指定しようとして「効かない！」と悩まないこと。
3.  **「インライン要素（aタグやspanなど）」をボタンのように大きくしたいなら `display: flex;` か `display: block;` に変更する。**
    *   これで `width` や `padding` が自由に使えるようになります。

原始的な方法を知ることで、「今のFlexboxがいかに楽で、強力か」が実感できるはずです。次は、このFlexboxのパワーをさらに引き出す**「レスポンシブ（メディアクエリ）」**について見ていきましょうか？
