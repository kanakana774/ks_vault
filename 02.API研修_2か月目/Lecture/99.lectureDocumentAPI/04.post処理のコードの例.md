# Spring Boot + MyBatis：POST処理（新規登録）

## 2. 具体的な実装コード

最初に「タグの新規登録API」を作ります。
DBのIDは自動採番（Auto Increment）とします。

### 前提：リクエストとテーブル
**リクエスト (JSON)**
testという名前のタグを作成したいとすると、、、
```json
{
  "name": "test"
}
```

**データベース (Tagテーブル)**
最終的に下記のように==登録する値==をtagテーブルに入れて、登録成功のお知らせをフロントに返すとこまでしたいです。

| カラム名      | 型       |       | 備考                              | ==登録する値== |
| :-------- | :------ | ----- | :------------------------------ | --------- |
| `tag_id`  | INT     | タグのID | Primary Key, **AUTO_INCREMENT** | 1（自動採番）   |
| `name`    | VARCHAR | タグの名前 | not unll                        | test      |
| `version` | INT     | 更新回数  | not null                        | 0         |

### Controller
```java
package jp.aevic.todo.app.controller.tag;

// import省略

/**
 * TagController
 * 
 */
@RestController
@RequestMapping(path = "/tags")
public class TagController {

    // 依存クラス
    private final LocationUtil locationUtil;
    private final TagService service;

    /**
     * コンストラクタ
     * 
     * @param locationUtil
     * @param service
     */
    @Autowired
    public TagController(LocationUtil locationUtil, TagService service) {
        // コンストラクタインジェクション
        this.locationUtil = locationUtil;
        this.service = service;
    }

    /**
     * タグ新規作成
     * 
     * @param form
     * @return ResponseEntity<Void>
     */
    @PostMapping
    public ResponseEntity<Void> postNewTag(@RequestBody @Validated TagPostFrom form) {
		
        // Entity作成
        TagEntity tagEntity = new TagEntity();
        tagEntity.setName(form.getName());
        tagEntity.setVersion(0);
		
        // Service呼び出し
        int tagId = service.createNewTag(tagEntity);
		
        // Header作成
        URI location = locationUtil.create(CreatedLocationPaths.TAG, tagId);
        return ResponseEntity.created(location).build();
    }
}

```

### Service
```java
package jp.aevic.todo.logic.service.tag;

// import省略

/**
 * TagService
 * 
 */
@Service
public class TagService {

    // 依存クラス
    private final TagMapper mapper;

    /**
     * コンストラクタ
     * 
     * @param mapper
     */
    @Autowired
    public TagService(TagMapper mapper) {
        // コンストラクタインジェクション
        this.mapper = mapper;
    }

    /**
     * タグ新規作成
     * 
     * @param tagEntity
     * @return int
     */
    public int createNewTag(TagEntity tagEntity) {
        // Mapper呼び出し
        mapper.insertTag(tagEntity);
        // 自動採番されたtagId取得
        return tagEntity.getTagId();
    }
}
```


### Mapper Interface
```java
package jp.aevic.todo.mapper.tag;

import org.apache.ibatis.annotations.Mapper;
import jp.aevic.todo.entity.tag.TagEntity;

/*
 * TagMapperインタフェース
 * 
 */
@Mapper
public interface TagMapper {

    /*
     * タグの新規登録
     */
    void insertTag(TagEntity tagEntity);
}
```

### Mapper XML (SQL)
ここが重要ポイントです。`useGeneratedKeys`を使うことで、INSERT実行直後に発行されたIDをJava側で扱えるようになります。

```xml
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="jp.aevic.todo.mapper.tag.TagMapper">
		
        <insert id="insertTag" parameterType="jp.aevic.todo.entity.tag.TagEntity" useGeneratedKeys="true" keyProperty="tagId">
	        
            INSERT INTO Tag (name,version) values (#{name},#{version});
		    
        </insert>
		
</mapper>
```
