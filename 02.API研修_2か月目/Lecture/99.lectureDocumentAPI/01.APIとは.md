# API とは

**API（Application Programming Interface）** とは、ソフトウェアの機能を外部から利用するための「**規格**」や「**窓口**」のことです。

**「中身を知らなくても使える」という利点**
例えば、Javaの `List` インターフェースを使う時、`add()` メソッドの内部でメモリがどう管理されているかを知らなくても、データを追加できますよね。

```java
list.add("hoge"); // 内部実装を知らなくても機能を利用できる
```
このように、「内部の複雑さを隠蔽し、外から使いやすくする窓口（インターフェース）」がAPIの本質です。このようなAPIを積極的に使うことで、開発コストの削減にもつながります。

> [!hint]
> 例えば、、、
> スマートフォンで電話をかける際に、iosなのかandroidなのかをあまり意識しないはずです。これは電話をかける操作の手順やUIなどが一定の規格に沿って作られてるからです。
> 使い方さえ知っていれば、内部の処理を気にせず使えるので、まさにインタフェースのようです。

**Web API への応用**
これをWebの世界に広げたのが **Web API** です。
プログラム内部のクラス呼び出しだけでなく、インターネット越しにある「Googleマップ」や「天気予報サーバー」の機能も、決められた窓口（URLやデータ形式）に従ってリクエストを送るだけで利用できます。

これにより、自社で開発しきれない機能でも、外部サービスを部品のように組み合わせて開発することが可能になります。

# 一般公開されてる API を呼んでみる

天気を知ることができる API を呼んでみる。

openweathermapAPI の仕様書：
https://openweathermap.org/api

```bash
http://api.openweathermap.org/data/2.5/weather?q={city}&appid={key}&lang=ja&units=metric
```

```bash
curl -v "http://api.openweathermap.org/data/2.5/forecast?q=Tokyo,JP&appid=ae81af837c57a19a9d85e5e682158d92&lang=ja&units=metric"
```
