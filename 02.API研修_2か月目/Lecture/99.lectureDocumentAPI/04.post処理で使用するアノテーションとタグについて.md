# Spring Boot + MyBatis：POST処理（新規登録）

## 1. アノテーションとXMLの役割整理

### From（データの入れ物）

| アノテーション                        | 説明                | POST時の役割                  |
| :----------------------------- | :---------------- | :------------------------ |
| **`@NotBlank`**                | 空を許さない            | 違反してる場合、400badRequestを返す。 |
| **`@Size(min = 1, max = 30)`** | 1文字以上30文字以内しか許さない | 違反してる場合、400badRequestを返す。 |

### Controller（入り口）
HTTPリクエストを受け取り、Javaオブジェクトに変換します。

| アノテーション                                | 説明                         | POST時の役割                                             |
| :------------------------------------- | :------------------------- | :--------------------------------------------------- |
| **`@RestController`**                  | APIコントローラー宣言               | springのBeanとして管理対象であることを示す。また、Controllerクラスとして認識させる。 |
| **`@RequestMapping(value = "/tags")`** | 指定したパスのリクエストをクラスにmappingする | `/tags`でリクエストが来た場合に、このクラスを使うように設定する。                 |
| **`@PostMapping`**                     | HTTP POSTメソッドの指定           | 新規登録処理のURLを定義する。                                     |
| **`@RequestBody`**                     | ボディのJSONを受け取る              | 送られてきたJSONデータを、Javaのクラス（Form）に詰め替える。                 |
| **`@Validated`**                       | 引数のオブジェクトの検証               | 引数のオブジェクトに設定されてるアノテーションの検証内容をチェックする。                 |

### Service（ビジネスロジック）
| アノテーション              | 説明         | POST時の役割                                          |
| :------------------- | :--------- | :------------------------------------------------ |
| **`@Service`**       | サービスクラス宣言  | springのBeanとして管理対象であることを示す。また、Serviceクラスとして認識させる。 |

### MyBatis Mapper（インターフェース）
| アノテーション | 説明 | POST時の役割 |
| :--- | :--- | :--- |
| **`@Mapper`** | マッパー宣言 | MyBatisがこのインターフェースを見つけ、実装クラスを自動生成する。 |

### MyBatis XML（SQL記述）
| タグ/属性 | 説明 |
| :--- | :--- |
| **`<insert>`** | INSERT文を記述するタグ。 |
| **`useGeneratedKeys="true"`** | **重要**：DB側でAUTO_INCREMENT等で自動生成されたIDを、MyBatis側で取得する設定。 |
| **`keyProperty="id"`** | 取得した自動生成IDを、Javaオブジェクトのどのフィールドにセットするか指定する。 |
