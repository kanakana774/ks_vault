## A. リスト分割法（あなたのコードの整理）

あなたのロジック（`currentNumber` が空なら負の符号）は正しく機能します。この方法は「トークン化（分割）」と「計算」を素直に実装したもので、直感的で分かりやすいのが特徴です。

コードを少し整理し、コメントでロジックを補足しました。

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class CalculatorListSplit {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.println("計算式を入力 (例: 4 * -5 + 10 - -3)");
        String input = scanner.nextLine();
        
        try {
            double result = calculate(input);
            System.out.println("結果: " + formatResult(result));
        } catch (Exception e) {
            System.out.println("エラー: " + e.getMessage());
        }
    }

    private static String formatResult(double result) {
        if (result == (long) result) return String.format("%d", (long) result);
        return String.format("%s", result);
    }

    public static double calculate(String expression) {
        List<Double> numbers = new ArrayList<>();
        List<Character> operators = new ArrayList<>();
        StringBuilder currentNumber = new StringBuilder();

        for (int i = 0; i < expression.length(); i++) {
            char c = expression.charAt(i);

            if (c == ' ') continue;

            // 数字または小数点の場合
            if (Character.isDigit(c) || c == '.') {
                currentNumber.append(c);
            } 
            // 演算子 (+, -, *, /) の場合
            else if (isOperator(c)) {
                // 【重要】マイナス記号の判定ロジック
                // バッファが空＝直前に数字がない＝これは「負の符号」である
                if (c == '-' && currentNumber.length() == 0) {
                    currentNumber.append(c);
                } 
                else {
                    // 通常の演算子として処理
                    if (currentNumber.length() > 0) {
                        numbers.add(Double.parseDouble(currentNumber.toString()));
                        currentNumber.setLength(0); // バッファクリア
                    }
                    operators.add(c);
                }
            } else {
                throw new IllegalArgumentException("無効な文字: " + c);
            }
        }

        // 末尾の数字を追加
        if (currentNumber.length() > 0) {
            numbers.add(Double.parseDouble(currentNumber.toString()));
        }

        // 計算フェーズ1: 乗算・除算 (*, /)
        int i = 0;
        while (i < operators.size()) {
            char op = operators.get(i);
            if (op == '*' || op == '/') {
                double num1 = numbers.get(i);
                double num2 = numbers.get(i + 1);
                double res = (op == '*') ? (num1 * num2) : (num1 / num2);

                numbers.set(i, res);      // 結果で置き換え
                numbers.remove(i + 1);    // 使った数字を削除
                operators.remove(i);      // 使った演算子を削除
            } else {
                i++;
            }
        }

        // 計算フェーズ2: 加算・減算 (+, -)
        double finalResult = numbers.get(0);
        for (int j = 0; j < operators.size(); j++) {
            char op = operators.get(j);
            double nextNum = numbers.get(j + 1);

            if (op == '+') finalResult += nextNum;
            else if (op == '-') finalResult -= nextNum;
        }

        return finalResult;
    }

    private static boolean isOperator(char c) {
        return c == '+' || c == '-' || c == '*' || c == '/';
    }
}
```

## B. 再帰下降構文解析法 (Recursive Descent Parser)

これはコンパイラや電卓アプリを作る際の**「王道」**です。
数式の構造（足し算より掛け算が先、など）をメソッドの呼び出し関係で表現します。この方法の最大の利点は、**カッコ `()` の対応が非常に簡単に追加できること**です。

### アプローチのポイント
1.  **`expression()`**: 足し算・引き算を処理するメソッド
2.  **`term()`**: 掛け算・割り算を処理するメソッド
3.  **`factor()`**: 数字や負の数を処理するメソッド

「足し算をする前に掛け算の結果が必要」なので、メソッドの中で次の優先順位のメソッドを呼び出します。

```java
import java.util.Scanner;

public class RecursiveParser {
    private String text;
    private int pos = 0; // 現在読んでいる文字の位置

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.println("計算式を入力 (例: 4 * -5 + 10)");
        String input = scanner.nextLine();
        
        RecursiveParser parser = new RecursiveParser(input);
        System.out.println("結果: " + parser.parse());
    }

    public RecursiveParser(String text) {
        this.text = text.replace(" ", ""); // 空白除去
    }

    public double parse() {
        pos = 0;
        return expression();
    }

    // 足し算・引き算 (優先度: 低)
    private double expression() {
        double v = term(); // まず掛け算・割り算を計算させる

        while (pos < text.length()) {
            char op = text.charAt(pos);
            if (op != '+' && op != '-') break;
            
            pos++; // 演算子を進める
            double v2 = term();

            if (op == '+') v += v2;
            else if (op == '-') v -= v2;
        }
        return v;
    }

    // 掛け算・割り算 (優先度: 高)
    private double term() {
        double v = factor(); // まず数字(またはカッコ)を取得

        while (pos < text.length()) {
            char op = text.charAt(pos);
            if (op != '*' && op != '/') break;

            pos++;
            double v2 = factor();

            if (op == '*') v *= v2;
            else if (op == '/') v /= v2;
        }
        return v;
    }

    // 数字 または 負の数 (最小単位)
    private double factor() {
        if (pos >= text.length()) throw new RuntimeException("式が途中で終わっています");

        char c = text.charAt(pos);

        // ★ここがマイナス対応の肝★
        // ここで '-' が来たら、自分自身(factor)を再帰呼び出しして符号を反転させる
        if (c == '-') {
            pos++;
            return -factor();
        }

        // 数字の読み取り
        StringBuilder sb = new StringBuilder();
        while (pos < text.length()) {
            c = text.charAt(pos);
            if (Character.isDigit(c) || c == '.') {
                sb.append(c);
                pos++;
            } else {
                break;
            }
        }
        
        if (sb.length() == 0) throw new RuntimeException("数字が期待される位置に文字があります: " + c);
        return Double.parseDouble(sb.toString());
    }
}
```

## C. 逆ポーランド記法 (RPN) + 操車場アルゴリズム

これは、人間が書く数式（中置記法 `1 + 2`）を、コンピュータが計算しやすい形（後置記法 `1 2 +`）に変換してから計算する方法です。
Stack（スタック）というデータ構造をフル活用します。

### アプローチのポイント
1.  **変換フェーズ**: `1 + 2 * 3` → `1 2 3 * +` というリストに変換する。
2.  **計算フェーズ**: リストを左から読み、演算子が出たら直前の2つの数字を計算する。

あなたの「バッファが空なら負の符号」というロジックは、この変換フェーズでもそのまま使えます。

```java
import java.util.*;

public class RPNCalculator {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.println("計算式を入力 (例: 5 + 4 * -3)");
        String input = scanner.nextLine();

        try {
            // 1. 中置記法 -> 逆ポーランド記法(RPN)
            List<String> rpn = toRPN(input);
            System.out.println("RPN変換: " + rpn); 

            // 2. 計算
            System.out.println("結果: " + calcRPN(rpn));
        } catch (Exception e) {
            System.out.println("エラー: " + e.getMessage());
        }
    }

    // 操車場アルゴリズムによる変換
    private static List<String> toRPN(String input) {
        List<String> output = new ArrayList<>();
        Deque<Character> stack = new ArrayDeque<>();
        
        for (int i = 0; i < input.length(); i++) {
            char c = input.charAt(i);
            if (c == ' ') continue;

            // 数字または負の数の判定
            // 「マイナス」かつ「先頭 または 直前が数字/右カッコではない」場合
            boolean isNegativeSign = (c == '-') && 
                (i == 0 || (!Character.isDigit(input.charAt(i-1)) && input.charAt(i-1) != ')'));

            if (Character.isDigit(c) || isNegativeSign) {
                StringBuilder sb = new StringBuilder();
                if (isNegativeSign) {
                    sb.append('-'); 
                    i++;
                }
                while (i < input.length() && (Character.isDigit(input.charAt(i)) || input.charAt(i) == '.')) {
                    sb.append(input.charAt(i));
                    i++;
                }
                output.add(sb.toString());
                i--; // ループの増分調整
            }
            else if (c == '(') {
                stack.push(c);
            }
            else if (c == ')') {
                while (!stack.isEmpty() && stack.peek() != '(') output.add(String.valueOf(stack.pop()));
                stack.pop(); // '('を捨てる
            }
            else if ("+-*/".indexOf(c) != -1) {
                while (!stack.isEmpty() && precedence(stack.peek()) >= precedence(c)) {
                    output.add(String.valueOf(stack.pop()));
                }
                stack.push(c);
            }
        }
        while (!stack.isEmpty()) output.add(String.valueOf(stack.pop()));
        return output;
    }

    // RPNの計算処理
    private static double calcRPN(List<String> rpn) {
        Deque<Double> stack = new ArrayDeque<>();
        for (String token : rpn) {
            if ("+-*/".contains(token) && token.length() == 1) {
                double b = stack.pop();
                double a = stack.pop();
                switch (token.charAt(0)) {
                    case '+': stack.push(a + b); break;
                    case '-': stack.push(a - b); break;
                    case '*': stack.push(a * b); break;
                    case '/': stack.push(a / b); break;
                }
            } else {
                stack.push(Double.parseDouble(token));
            }
        }
        return stack.pop();
    }

    private static int precedence(char op) {
        if (op == '*' || op == '/') return 2;
        if (op == '+' || op == '-') return 1;
        return 0;
    }
}
```

## 比較とまとめ

3つの方法を比較します。

| 特徴 | A. リスト分割法（あなたの案） | B. 再帰下降構文解析 | C. 逆ポーランド記法 |
| :--- | :--- | :--- | :--- |
| **難易度** | **易しい** | 普通 | やや難しい |
| **コード量** | 短い | 普通 | 長い |
| **拡張性** | 低い（カッコ対応などが困難） | **高い**（カッコや関数追加が楽） | 高い（一度作れば強力） |
| **処理効率** | リスト操作が多くやや遅い | 高速 | **非常に高速** |
| **負の数の判定** | バッファが空かどうか | 再帰時に `-` を検知するか | トークン読み取り時に判定 |

### 結論

*   **今の要件（カッコなし、四則演算のみ）なら**：
    **A. リスト分割法（あなたの案）** が最もコードが短く、直感的で素晴らしい解決策です。「バッファが空なら負の符号」という着眼点は非常に鋭いです。

*   **もし「( )」を含めた計算が必要なら**：
    **B. 再帰下降構文解析** をおすすめします。コードの構造自体が数式の構造を表しており、論理的に記述できます。

*   **汎用的な電卓ライブラリを作るなら**：
    **C. 逆ポーランド記法** が適しています。一度RPNに変換してしまえば、計算処理が極めて単純でバグが出にくいためです。

## A. リスト分割法（あなたのオリジナル案）

バッファ（`currentNumber`）の状態を見てマイナス記号の役割を判断する方法です。
「演算子リスト」と「数値リスト」を作ってから、優先順位に従って計算します。

*   **マイナス判定:** `currentNumber` が空の状態で `-` が来たら「負の符号」とする。

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class CalculatorListSplit {
    public static void main(String[] args) {
        // 入力例: 4 * -5 + 10 - -3
        String input = "4 * -5 + 10 - -3"; 
        System.out.println("A. リスト分割法: " + calculate(input));
    }

    public static double calculate(String expression) {
        List<Double> numbers = new ArrayList<>();
        List<Character> operators = new ArrayList<>();
        StringBuilder currentNumber = new StringBuilder();

        for (int i = 0; i < expression.length(); i++) {
            char c = expression.charAt(i);

            if (c == ' ') continue;

            if (Character.isDigit(c) || c == '.') {
                currentNumber.append(c);
            } else if (isOperator(c)) {
                // ★判定ロジック: バッファが空なら「負の符号」
                if (c == '-' && currentNumber.length() == 0) {
                    currentNumber.append(c);
                } else {
                    if (currentNumber.length() > 0) {
                        numbers.add(Double.parseDouble(currentNumber.toString()));
                        currentNumber.setLength(0);
                    }
                    operators.add(c);
                }
            }
        }
        if (currentNumber.length() > 0) {
            numbers.add(Double.parseDouble(currentNumber.toString()));
        }

        // 計算1: 乗算・除算 (*, /)
        int i = 0;
        while (i < operators.size()) {
            char op = operators.get(i);
            if (op == '*' || op == '/') {
                double v1 = numbers.get(i);
                double v2 = numbers.get(i + 1);
                numbers.set(i, (op == '*') ? v1 * v2 : v1 / v2);
                numbers.remove(i + 1);
                operators.remove(i);
            } else {
                i++;
            }
        }

        // 計算2: 加算・減算 (+, -)
        double result = numbers.get(0);
        for (int j = 0; j < operators.size(); j++) {
            char op = operators.get(j);
            double next = numbers.get(j + 1);
            if (op == '+') result += next;
            else if (op == '-') result -= next;
        }
        return result;
    }

    private static boolean isOperator(char c) {
        return c == '+' || c == '-' || c == '*' || c == '/';
    }
}
```

## B. 2つのスタック法（Dequeを使用）

これがいわゆる**「アルゴリズムとしての正攻法」**です。
`java.util.ArrayDeque` をスタック（LIFO）として使用します。

1.  **数値用スタック (`values`)**: 数字を積む
2.  **演算子用スタック (`ops`)**: `+ - * /` を積む

演算子が登場したとき、**「今スタックにある演算子」の方が優先順位が高ければ先に計算してしまう**ことで、優先順位（`* /` 先行）を守ります。

*   **マイナス判定:** 文字列を走査する際、「先頭」または「直前が数字でない」場合に `-` が来たら「負の符号」とみなします。

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class CalculatorStack {
    public static void main(String[] args) {
        String input = "4 * -5 + 10 - -3";
        System.out.println("B. スタック法: " + calculate(input));
    }

    public static double calculate(String expression) {
        Deque<Double> values = new ArrayDeque<>();
        Deque<Character> ops = new ArrayDeque<>();

        for (int i = 0; i < expression.length(); i++) {
            char c = expression.charAt(i);
            if (c == ' ') continue;

            // ★判定ロジック: 先頭、または直前が数字じゃない場合の '-' は負号
            boolean isNegativeSign = (c == '-') && 
                (i == 0 || (!Character.isDigit(expression.charAt(i - 1)) && expression.charAt(i - 1) != ' '));

            // 数字、または負号の処理
            if (Character.isDigit(c) || isNegativeSign) {
                StringBuilder sb = new StringBuilder();
                
                // 負号なら先に追加してインデックスを進める
                if (isNegativeSign) {
                    sb.append('-');
                    i++;
                }
                
                // 続く数字を全部読み取る
                while (i < expression.length() && (Character.isDigit(expression.charAt(i)) || expression.charAt(i) == '.')) {
                    sb.append(expression.charAt(i));
                    i++;
                }
                values.push(Double.parseDouble(sb.toString()));
                i--; // ループで進みすぎた分を戻す
            } 
            // 演算子の処理
            else if (c == '+' || c == '-' || c == '*' || c == '/') {
                // スタック内の優先度が高い演算子を先に処理する
                while (!ops.isEmpty() && precedence(ops.peek()) >= precedence(c)) {
                    double val2 = values.pop();
                    double val1 = values.pop();
                    values.push(applyOp(ops.pop(), val1, val2));
                }
                ops.push(c);
            }
        }

        // 残った計算を処理
        while (!ops.isEmpty()) {
            double val2 = values.pop();
            double val1 = values.pop();
            values.push(applyOp(ops.pop(), val1, val2));
        }

        return values.pop();
    }

    // 優先順位（高いほど数値が大きい）
    private static int precedence(char op) {
        if (op == '+' || op == '-') return 1;
        if (op == '*' || op == '/') return 2;
        return 0;
    }

    // 計算実行
    private static double applyOp(char op, double a, double b) {
        switch (op) {
            case '+': return a + b;
            case '-': return a - b;
            case '*': return a * b;
            case '/': return a / b;
        }
        return 0;
    }
}
```

## 番外編. ScriptEngine（Java標準のJSエンジン）

## 全体の比較・まとめ

| 特徴 | A. リスト分割法（あなたの案） | B. 2つのスタック法 | 番外編. ScriptEngine |
| :--- | :--- | :--- | :--- |
| **ロジックの核** | バッファが空なら負 | 優先順位を見ながらStack操作 | JSエンジンに丸投げ |
| **コード量** | 普通 | やや多い | **極小** |
| **処理効率** | リストを何度も走査するため遅め | **1回の走査で済むため高速** | コンパイルコストがあり重い |
| **拡張性** | カッコ `()` 対応などが難しい | カッコ対応が容易（王道） | 何でもできる（関数なども可） |
| **難易度** | **易しい**（直感的） | 中級（アルゴリズムの知識要） | 易しい（環境依存のみ注意） |

### 結論としてどれがいい？

1.  **「とりあえず動くものが作りたい」「ロジックを自分で把握したい」**
    👉 **A. リスト分割法**（あなたの書いたコード）がベストです。直感的で素晴らしいアイデアです。

2.  **「将来的にカッコ `( )` も入れたい」「プログラミングの勉強として本格的なものを知りたい」**
    👉 **B. 2つのスタック法** をおすすめします。これが電卓プログラムの標準的な作り方です。

3.  **「実務でとにかく楽をして計算機能を実装したい」**
    👉 **番外編. ScriptEngine** を使います（ただしJavaのバージョンに注意）。
