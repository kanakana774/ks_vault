# 閏年判定 ― 全パターン比較

## 1. 有効な組み合わせ一覧（矛盾を除外）

| No | 4で割切 | 100で割切 | 400で割切 | 実例 | 正解 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| ① | ✕ | ✕ | ✕ | 2023 | 平年 |
| ② | ○ | ✕ | ✕ | 2024 | 閏年 |
| ③ | ○ | ○ | ✕ | 1900 | 平年 |
| ④ | ○ | ○ | ○ | 2000 | 閏年 |

### ❌ 存在しないパターン（論理的に不可能）
*   **100で割れるが 4 で割れない**
*   **400で割れるが 100 で割れない**

> ※ 400 ⊂ 100 ⊂ 4 の包含関係があるため、これらは成立しません。

---

## 2. 判定ロジックの分類

| 記号 | 分類 | 概要 |
|:---:|:---|:---|
| **A** | 例外先行・即確定 | 400 → 100 → 4 の順で判定 |
| **B** | 逆順・即確定（バグ） | 4 → 100 → 400 の順で判定（早期リターンの誤用） |
| **Bʼ** | 逆順・ネスト | 4 → 100 → 400 を入れ子構造で判定 |
| **Bʼʼ** | 逆順・ネスト（!=0） | ネストを維持しつつ、条件を反転（!=0）させて整理 |
| **C** | 逆順・上書き | フラグを用意し、後続の条件で値を上書き補正 |
| **D** | 論理式 | 数学的な1行の条件式で判定 |

## 4. 各ロジックの代表コード（要点）

### A：例外先行（推奨）
```java
if (year % 400 == 0) return true;
if (year % 100 == 0) return false;
return year % 4 == 0;
```

### B：逆順・即確定（NG例）
```java
if (year % 4 == 0) return true;    // ここで確定してしまうため、以降の100, 400が無視される
if (year % 100 == 0) return false;
if (year % 400 == 0) return true;
return false;
```

### Bʼ：逆順・ネスト（正解）
```java
if (year % 4 == 0) {
    if (year % 100 == 0) {
        if (year % 400 == 0) {
            return true;
        } else {
            return false;
        }
    } else {
        return true;
    }
}
return false;
```

### Bʼʼ：逆順・ネスト（year % 100 != 0）
```java
if (year % 4 == 0) {
    if (year % 100 != 0) {
        return true;
    } else {
        if (year % 400 == 0) {
            return true;
        } else {
            return false;
        }
    }
}
return false;
```

### C：逆順・上書き
```java
boolean leap = false;
if (year % 4 == 0)   leap = true;
if (year % 100 == 0) leap = false;
if (year % 400 == 0) leap = true;
return leap;
```

### D：論理式
```java
return year % 400 == 0 || (year % 4 == 0 && year % 100 != 0);
```

## 6. 結論（分類軸ごと）

*   **正しさ ＋ 説明性** → **A**（最も意図が伝わりやすくミスが少ない）
*   **包含関係をコードで表現** → **Bʼ / Bʼʼ**（数学的な構造を反映）
*   **状態遷移として理解** → **C**（フィルタリングしていく思考）
*   **最短・数学的** → **D**（ライブラリの実装などで一般的）
*   **アンチパターン** → **B**（早期リターンの順序ミス）
