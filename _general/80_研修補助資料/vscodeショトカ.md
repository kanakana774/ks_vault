### **全般**
| 操作概要 | キーボード ショートカット |
| :--- | :--- |
| すべてのコマンドの表示 | `Ctrl` + `Shift` + `P`, `F1` |
| クイックオープン (ファイル移動) | `Ctrl` + `P` |
| キーボード ショートカットを開く | `Ctrl` + `K` `Ctrl` + `S` |
| 直近で開いたファイルを表示 | `Ctrl` + `Tab` |

### **編集**
| 操作概要 | キーボード ショートカット |
| :--- | :--- |
| コードの整形 | `Shift` + `Alt` + `F` |
| （選択範囲なしで）行の切り取り | `Ctrl` + `X` |
| （選択範囲なしで）行のコピー | `Ctrl` + `C` |
| 行を下へ移動 | `Alt` + `↓` |
| 行を上へ移動 | `Alt` + `↑` |
| 行を下へコピー | `Shift` + `Alt` + `↓` |
| 行を上へコピー | `Shift` + `Alt` + `↑` |
| 行の削除 | `Ctrl` + `Shift` + `K` |
| 行を下に挿入 | `Ctrl` + `Enter` |
| 行のインデント追加 | `Ctrl` + `]` |
| 行のインデント削除 | `Ctrl` + `[` |
| 名前を変更 (リファクタリング) | `F2` |
| 補完候補を開く | `Ctrl` + `Space` |
| 行コメントの切り替え | `Ctrl` + `/` |

### **選択**
| 操作概要 | キーボード ショートカット |
| :--- | :--- |
| 矩形選択 (マウス使用) | `Shift` + `Alt` + `ドラッグ` |
| 矩形選択 (キーボードのみ) | `Ctrl` + `Shift` + `Alt` + `方向キー` |
| 選択範囲と同じ文字列の複数指定 | `Ctrl` + `D` |

### **移動**
| 操作概要 | キーボード ショートカット |
| :--- | :--- |
| 行の先頭に移動 | `Home` |
| 行の最後に移動 | `End` |
| ファイルの先頭に移動 | `Ctrl` + `Home` |
| ファイルの末尾に移動 | `Ctrl` + `End` |
| 指定行へ移動 | `Ctrl` + `G` |
| 前に戻る (カーソル位置) | `Alt` + `←` |
| 次に進む (カーソル位置) | `Alt` + `→` |

### **検索**
| 操作概要 | キーボード ショートカット |
| :--- | :--- |
| ファイル内検索 | `Ctrl` + `F` |
| ファイル内置換 | `Ctrl` + `H` |
| 次を検索 | `F3` |
| 前を検索 | `Shift` + `F3` |
| プロジェクト内検索 | `Ctrl` + `Shift` + `F` |

### **パネル操作**
| 操作概要 | キーボード ショートカット |
| :--- | :--- |
| サイドバーの表示/非表示 | `Ctrl` + `B` |
| ターミナルの表示/非表示 | `Ctrl` + `@` |
| 新しく統合ターミナルを表示 | `Ctrl` + `Shift` + `@` |
| エクスプローラーの表示 | `Ctrl` + `Shift` + `E` |
