# 00_SQL研修_改訂

**【所有】個人（講師用）｜【種類】改訂作業中の教材｜【配布】まだしない**

---

SQL研修を「移植可能な知識に重心を戻す」方針で作り直すための**作業場**。

## なぜ `00_SQL研修/` の外にあるか

**既存資料を使った研修は毎月ある。汚せない。**
そして配布手順が「**`00_SQL研修` をコピーして `03_詳細版/` を削る**」なので、`00_SQL研修` の中に作業場を置くと**未完成の改訂版が配布物に混ざる**。外に出しておけば配布手順を一切変えずに済む。

- **`00_SQL研修/` には書き込まない。** 読むのはよい
- ここのファイルが揃って差し替えられる状態になったら、そのとき入れ替えを検討する
- **同じ basename のファイルを作らない**（Obsidian のリンク解決が曖昧になる）。既存章の改訂版を作るときは名前を変える

## 構成

- `01_講義資料/` … 新しい講義資料
- `02_問題/` … 問題ページ（**解答ページから機械生成する**）
- `04_解答/` … 解答ページ（**こちらが正本**）

書式は `00_SQL研修/04_解答/_問題・解答ページのフォーマット.md` に従う。
