# 10_シミュレーション — 研修を1周分、紙の上で回す

**目的は疎通。** 「やること」を示しながら、**これを渡すと／こんなものが出てくる**を並べて見せる。
水谷さんへの説明と、研修設計の抜け漏れ検出の両方に使う。

## 段ごとに3ファイル

| ファイル | 中身 |
|---|---|
| `NN_<段名>_やること.md` | **研修生の作業手順。** これを見せながら進める |
| `NN_<段名>_渡すもの.md` | 作業ごとの**入力**（現物だけ） |
| `NN_<段名>_出てくるもの.md` | 作業ごとの**出力** |

**3ファイルは作業番号で対応する。** 番号を揃えているので横に並べて読める。

## 見せる順番

```
やること⑥ → 渡すもの⑥ → 出てくるもの⑥ → やること⑦ → 渡すもの⑦ → 出てくるもの⑦ → …
```

## 約束

- **AIの出力は実測。** 実際に走らせた結果をそのまま貼る。「AIはこう言うだろう」で書かない
- **研修生の判断は想定。** 3か月目終わりの新人役で書く。**失敗を混ぜる**（完璧な答案は判定材料にならない）
- **設計の根拠はここに書かない。** 正本は `07_実施計画.md`（具体）と `06_研修の芯.md`（原則）
- **教材の不備の一覧もここに書かない。** 正本は `04_教材見直しの材料.md`
