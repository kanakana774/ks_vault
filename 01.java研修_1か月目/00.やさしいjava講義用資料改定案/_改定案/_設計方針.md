# 1か月目 Java講義資料 改定 設計方針

> このドキュメントは、1か月目（Java研修）講義資料を改定するにあたっての設計方針をまとめた「生きた指針」です。方針が固まり次第、随時更新します。

最終更新：2026-06-26

---

## 0. ゴール

- 1か月目の講義資料を「ちゃんとしたもの」にする。
- **説明の欠け**を埋め、**フォーマットを統一**し、**研修生の体験順**で破綻なく学べる流れにする。
- 講師（後任含む）が迷わず講義でき、研修生が後から復習できる資料にする。

---

## 1. 想定読者と閲覧環境

| 読者 | 環境 | 配慮 |
|---|---|---|
| **研修生** | **VS Code**（標準Markdownプレビュー） | Obsidian独自記法は使わない（崩れる）。VS Codeで色付き表示される記法を使う |
| **講師・後任** | Obsidian / VS Code | 進行・実演の意図を「進行メモ」に残す（引継ぎ兼用） |

> ⚠️ **Obsidianコールアウト（`> [!hint]` の小文字種別・折りたたみ `[!note]-`）は禁止。** VS Codeで `[!hint]` の文字がそのまま見えてしまう。

---

## 2. フォーマット標準

### 2-1. 見出し階層
- `#` = Lesson名（例：`# Lesson 1 - 始めの一歩`）
- `##` = 大項目
- `###` = 小項目

### 2-2. コールアウト（GitHub式アラート＝VS Code標準プレビューで色付き表示）

| 用途 | 記法 | 読者 |
|---|---|---|
| 例え話・補足 | `> [!NOTE]`（先頭に「💡 例え話」等） | 研修生 |
| **エディタ操作Tips** | `> [!TIP]`（先頭に「⌨️ **エディタ操作**：」） | 研修生（後で参照） |
| 重要 | `> [!IMPORTANT]` | 研修生 |
| つまずき注意 | `> [!WARNING]` | 研修生 |
| 致命的な注意 | `> [!CAUTION]` | 研修生 |

### 2-3. 進行メモ（講師の実演指示＋後任への引継ぎ）
- `<details><summary>🎤 進行メモ</summary>` … `</details>` で**折りたたみ**。
- HTMLなのでVS Codeでも折りたため、任意ラベルが付けられる。
- 中身の前後に**空行**を入れる（Markdownを正しくレンダリングさせるため）。
- 各セクション末に置く（該当箇所の近くに置くことで「説明漏れ防止」）。

### 2-4. その他
- コードは ` ```java ` で統一。コメントで意図を明示。
- 図は **mermaid** で統一。
- 各Lesson末に **`### ✅ Lesson N まとめ`**、ファイル末に **`## 📌 到達チェックリスト`** を置く。

### 2-5. 補足コンテンツは「3種類」を区別する
| 種類 | 例 | 記法 |
|---|---|---|
| A. 進行・実演の指示 | 「ここでエラーをわざと起こす」 | 🎤 進行メモ（`<details>`） |
| B. エディタ操作Tips | `Ctrl+Space`で補完 | `> [!TIP]` |
| C. 例え話・補足 | 「バケツとコップ」 | `> [!NOTE]` 等 |

## 3. 内容（エディトリアル）方針

- **研修生の体験順で設計する。** 前のLessonで未習の用語をいきなり使わない。前方参照する場合は注記する。
- **専門用語・概念を出しすぎない／早すぎない。** 例：OOPはLesson1では「雰囲気だけ」、本格化はLesson9〜。
- **初学者のつまずき所を明示する。** 例：整数同士の割り算の切り捨て（`5/2=2`）、double誤差、演算子の優先順位、`==` と `equals`（Lesson5）など。
- **正確さ。** 図や記法の誤りを直す（例：UMLの継承記法 `<|--` をインスタンス化の説明に使わない）。
- **概念→具体の順序。** 例：リテラルを「型の不一致」より先に説明する。
- **2か月目への接続を意識する。** 値渡し/参照渡し・コレクション・OOP・例外・電卓課題は、2か月目（API研修）で前提知識として参照される。

---

## 4. 作業の進め方（手戻り防止）

1. **1ファイルずつ**：精読 → 不足・不揃いの指摘 → 改定案を出力 → 議論 → fix → 固める。
2. 改定案は**元ファイルを残し**、`_改定案/` に**同名**で出力する。
3. 一気にやらない（手戻りが大きいため）。
