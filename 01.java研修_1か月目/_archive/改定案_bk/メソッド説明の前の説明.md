# メソッド学習の前に：Javaの「道具」を使いこなす共通ルール

Javaには、世界中のプログラマが作った便利な「道具（メソッド）」が最初からたくさん入っています。これらをググって自力で使うためには、**「ドット（`.`）の左側に何を書くか」**という2つのパターンを知るだけでOKです。

## 1. 共通のルール： `ターゲット . メソッド名 (引数)`

Javaのメソッドを呼び出すときは、必ず「どの道具を使うか」というターゲットをドット（`.`）の左に書きます。

---

## 2. パターンA：道具箱の名前を直接書く（static型）
**「いつでも、どこでも、すぐ使える」** 道具です。数学の計算や、型の変換などによく使われます。

- **特徴**: ドットの左側が **「大文字から始まる名前（クラス名）」** です。
- **イメージ**: 公園の遊具や、街の公衆電話のように、準備なしで誰でもいきなり使えます。

| 呼び出し例 | 意味 |
| :--- | :--- |
| **`Math.pow(2, 3)`** | **Math（数学道具箱）**の中にある、累乗計算メソッドを使う |
| **`Integer.parseInt("10")`** | **Integer（整数道具箱）**の中にある、数値変換メソッドを使う |

---

## 3. パターンB：準備したマシンの名前を書く（インスタンス型）
**「まずマシンを準備（用意）してから使う」** 道具です。キーボード入力や、ランダムな数字の作成、特定の文字列の加工に使われます。

- **特徴**: ドットの左側が **「自分で決めた変数名（小文字で始まることが多い）」** です。
- **イメージ**: 自分のスマホや、自分専用の炊飯器のようなものです。まず手元に用意（`new` など）してから使います。

| 呼び出し例 | 意味 |
| :--- | :--- |
| **`br.readLine()`** | **br（準備した読込マシン）**に対して、一行読んでと命令する |
| **`rand.nextInt(10)`** | **rand（準備した乱数マシン）**に対して、数字を出してと命令する |
| **`str.split(",")`** | **str（特定の文字列）**に対して、自分を分割してと命令する |

---

## 4. 【実践】ググって使い道を調べるコツ

「Java 文字列 分割」などで検索して、公式リファレンスや技術ブログを見たとき、以下のように書いてあったらこう読み解きましょう。

### 例①： `static` という文字が見えたら（Math.powなど）
> `public static double pow(double a, double b)`

- **読み解き方**: `static` と書いてあれば、**「クラス名.メソッド名」** でいきなり使えます。
- **使い方**: `Math.pow(2, 8)`

### 例②： `static` と書いていなかったら（String.splitなど）
> `public String[] split(String regex)`

- **読み解き方**: `static` がなければ、**「変数名.メソッド名」** で使います。
- **使い方**: 
  ```java
  String text = "A,B,C";
  text.split(","); // 変数text（実体）に対して使う
  ```

---

## 5. 次回への伏線

なぜ、「いきなり使える道具（パターンA）」と「準備が必要な道具（パターンB）」があるのでしょうか？

- **パターンA** は、誰が使っても結果のルールが同じもの（計算など）。
- **パターンB** は、「どのデータに対して行うか（どの文字列か、どの入力元か）」によって結果が変わるもの。

この違いを Lesson 9 以降で **「static（静的）」** と **「インスタンス（動的）」** という名前で詳しく解き明かしていきます。今は、**「ドットの左側が『大文字のクラス名』か『小文字の変数名』か」** を意識するだけで、Javaのコードがぐっと読みやすくなります！

### 💡 講師の方へ：導入のコツ

#### 1. VS Codeで「大文字 vs 小文字」を強調する
VS Codeで `Math.` と打つのと、`str.`（変数）と打つのを見せてください。
- 「ほら、`Math` は大文字だよね。これは道具箱の名前。`str` はさっき自分で作った変数の名前だよね」と視覚的に区別させます。

#### 2. `String.split()` の罠を教える
初心者はよく `String.split("A,B", ",")` と書こうとしてエラーになります。
- 「`split` は `String` クラスにあるけど、`static` じゃないんだ。だから、『分割したい文字列そのもの（変数）』にドットをつけて呼ばないといけないんだよ」と教えると、「ターゲット.メソッド」の原則が身に付きます。

#### 3. 「リファレンスの読み方」を1回だけ実演する
Googleで「Java Math pow」と検索し、Oracleの公式ドキュメントを開いてください。
- `static` という文字を探し、「ここに `static` ってあるから、`Math.pow()` って書けるんだよ」と教えます。
- 逆に `String.length()` などで `static` がないことを確認し、「だから `str.length()` って書くんだね」と対比させます。
- これを一度見せるだけで、彼らは「自力で調べる武器」を手に入れることができます。
