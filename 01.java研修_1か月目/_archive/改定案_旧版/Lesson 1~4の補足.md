# 補助資料：便利な「道具」の探し方・使い方

Javaには、世界中の先人たちが作った「便利な道具（メソッド）」がすでにたくさん用意されています。
すべてを暗記する必要はありません。大切なのは**「やりたいこと」を実現するためのコードをネットで見つけ、それを正しく自分のプログラムに組み込むスキル**です。

## 2. ブログなどの使用例（サンプルコード）の読み方
検索結果（技術ブログなど）で使用例を見つけたら、以下の**3つのポイント**に注目して、何が起こっているか想像してみましょう。

```java
// 使用例のイメージ
int result = Math.abs(-10);
```

1. **名前（メソッド名）**： `abs`（アブソリュート：絶対値）という名前の道具。
2. **入れるもの（引数）**： `(-10)` を道具に渡している。
3. **出てくる結果（戻り値）**： `result` という変数に結果が返ってきている。


## 3. 使い方の2大パターン
ネットで見つけた使用例は、だいたい以下のどちらかの「形」をしています。まずは**形を真似する**ことから始めましょう。

### パターンA：そのまま使える型
道具箱の名前（クラス名）を書いて、そのまま呼び出すパターンです。
- **見分け方**：`Math.〜` や `Integer.〜` のように、いきなり大文字で始まっている。

**【使用例のパターン】**
```java
// 数値の絶対値を出す Math.abs
int num = Math.abs(-5); 
```

### パターンB：準備してから使う型
使う前に「準備（`new`）」が必要なパターンです。
- **見分け方**：使う前に、1行 `new 〜` というコードが書いてある。

**【使用例のパターン】**
```java
// 乱数（ランダムな数）を作る Random
Random rand = new Random(); // モノを準備する（new）
int num = rand.nextInt(10);  // 準備した変数を使って実行
```

> **講師メモ：**
> - 仕組みは後回しでOK。「ネットで `new` がセットで紹介されていたら、自分のコードでも `new` を書く」という真似の仕方を教えます。

## 4. 自分のプログラムへの組み込み方（3ステップ）

ネットで見つけた使用例を、自分のコードにコピーする際の手順です。

### ステップ①：`import`（インポート）を確認する
ブログのコードの1番上の方に `import java.util.Random;` などの記述があれば、自分のコードの1番上にもそれを書きます。
※VS Codeなら、コードを貼り付けた後に赤波線が出たところで `Ctrl + .` を押せば、自動で解決してくれます。

### ステップ②：変数の型を合わせる
使用例で結果を `int` に入れているなら、自分も `int` の変数を用意します。

### ステップ③：値を自分の変数に置き換える
使用例の数字（リテラル）を、自分のプログラムで使っている変数に置き換えます。

## 5. 【実践例】課題で「絶対値を求めて」と言われたら

1. **検索**：「Java 絶対値 使い方」で検索。
2. **ブログ発見**：
   「`Math.abs()` を使うと絶対値が取れます。 `int a = Math.abs(-10);` のように書きます」という記事を見つける。
3. **分析**：
   - 呼び出し方： `Math.abs` なので「パターンA（そのまま）」だ！
   - 入れるもの： `-10`（整数）を入れている。
   - 返るもの： `int` の変数で受け取っている。
4. **自分のコードに書く**：
   ```java
   int myInput = -50; // 自分のプログラムにある値
   int result = Math.abs(myInput); // 見つけたパターンを真似して書く
   ```
