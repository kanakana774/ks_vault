# 課題：Todo機能とTag機能の統合

## 1. 目的
これまでに作成した「Todo管理機能」と「Tag管理機能」を紐づけ、**「Todoに複数のタグを設定・表示できる」**ように機能を拡張します。
リレーショナルデータベースにおける「多対多」の関係を、MyBatisを使ってどのようにJavaオブジェクトへマッピングするかもやってもらいます。

## 2. やること例
*   Todoの登録・更新時に、既存のタグを複数紐づけられること。
*   Todoの一覧・詳細取得時に、紐づいているタグ情報も一緒に取得できること。
*   Todoを削除した際に、中間テーブルの紐づけ情報も適切に削除されること。
*   **注意：** タグ自体のCRUD（タグの名前変更やタグ単体での削除など）は、既存のタグ機能をそのまま利用し、今回のTodo機能改修では手を加えないこと。

## 3. データベース構成
新たに中間テーブル `todo_tag` を導入します。

| todo_id | tag_id |
| :--- | :--- |
| 1 | 1 |
| 1 | 2 |
| 2 | 1 |

## 4. Javaエンティティの拡張
`TodoEntity` クラスに、紐づいているタグのリストを保持するフィールドを追加します。

```java
/**
 * TodoのEntityクラス
 */
@Data
public class TodoEntity {
    private int todoId;
    private String title;
    private String content;
    private int version;
    
    // 追加：Todoに紐づいているタグのリスト
    private List<TagEntity> tags;
}
```

## 5. MyBatisでの実装のポイント：ResultMapの活用
SQLで `JOIN` を行うと、結果はフラットな表形式で返ってきます。しかし、Java側では `TodoEntity` の中に `List<TagEntity>` を持たせる構造（集約）にしたいと考えています。

これを実現するために、MyBatisの **`resultMap`** 機能の中の **`<collection>`** タグを使用してください。

### ヒント
*   `resultMap` の `id` プロパティを使って、どの列がTodoの主キー（一意な行）かをMyBatisに伝えます。
*   `<collection>` タグを使うことで、結合によって複数行になったタグ情報を一つの `List<TagEntity>` にまとめてマッピングできます。
*   「MyBatis resultMap collection 1対多」などで検索して調べてみてください。

## 6. 各機能の実装方針

### ① 検索 (SELECT)
*   `todo` テーブルと `tag` テーブルを、中間テーブル `todo_tag` を介して `LEFT OUTER JOIN` します。
*   取得した結果を上述の `resultMap` で `TodoEntity` にマッピングします。

### ② 登録 (INSERT)
*   1回のAPIリクエストで以下の2ステップの処理を行います。
    1.  `todo` テーブルにデータを挿入する。
    2.  発番された `todo_id` と、画面から受け取った `tag_id` のリストを使って、`todo_tag` テーブルにレコードを挿入する。

### ③ 更新 (UPDATE)
*   Todo本体の情報を更新するとともに、タグの紐づけも更新します。
*   **推奨される手順:**
    1.  一度、対象の `todo_id` に紐づく `todo_tag` のレコードを全削除する。
    2.  改めて、現在の `tag_id` リストを `todo_tag` に一括挿入する。

### ④ 削除 (DELETE)
*   Todo本体を削除する前に、中間テーブル `todo_tag` から対象Todoに紐づくレコードを削除してください（参照整合性制約に注意）。

## 7. 開発ルール
データの受け渡しには、以下のクラス構成を維持してください。

*   **更新系 (POST / PUT):**
    *   `TodoForm` (リクエスト) → `TodoEntity` (DBエンティティ) → SQL
*   **参照系 (GET):**
    *   `TodoQuery` (リクエスト) → `TodoQueryCondition` (検索条件) → SQL

---

### アドバイス
この課題の難所は「SQLの結合結果をどうやってJavaのリスト構造に変換するか」というMyBatisの設定部分です。
まずはSQL単体で期待通りのデータ（TodoとTagが結合された状態）が取得できるかを確認してから、MyBatisの定義ファイル（XML）の記述に取り組むとスムーズです。
