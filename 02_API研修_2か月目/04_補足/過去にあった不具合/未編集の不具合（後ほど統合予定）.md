### mybatisで#{変数名}の箇所にjdbcType以外をいれると、、、
下記のようなエラーが、、、#{}
```
プロパティ「__frch_todoId_0」のパラメータマッピングにおいて、型ハンドラがnullでした。これは、javaType (jp.aevic.todo.entity.todo.TodoEntity) : jdbcType (null) の組み合わせに対して、型ハンドラが指定されていないか、または見つからなかったためです。
```

**「#{} の jdbcType に JDBC 型以外を入れると、MyBatis が TypeHandler を選べずエラーになる」**  
→ **jdbcType を正しく指定するか、そもそも書かない**のが最も安全。

### \ufeff（BOM付utf8）
エラーログで`\ufeff`が出てくる場合がある。これは、bom付utf8でファイルを保存していると起きる現象。vscode右下の文字コードをクリックし、エンコード付きで保存からutf8で保存しなおす。
