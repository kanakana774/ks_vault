### SQLの集合演算子とは

集合演算子は、2つ以上の`SELECT`文の結果を、行を追加する形で**縦方向に結合**するための演算子です。利用する際の注意点として、各`SELECT`文の**列の数とデータ型が一致している必要があります**。

### 1. UNION：和集合（重複を排除）

複数の`SELECT`文の結果を1つにまとめます。その際、**完全に重複する行は1行にまとめて表示**します。

#### 基本構文

```sql
SELECT 列リスト FROM テーブル1
UNION
SELECT 列リスト FROM テーブル2;
```

#### 具体例

`products_tmp`テーブルの商品名と`categories_tmp`テーブルのカテゴリ名を一覧表示します。`'Electronics'`と`'Smartphone'`は両方のテーブルに存在しますが、結果では1行ずつにまとめられます。

```sql
WITH products_tmp AS (
  SELECT 'Laptop' AS product_name UNION ALL
  SELECT 'Electronics' UNION ALL
  SELECT 'Mouse' UNION ALL
  SELECT 'Smartphone' UNION ALL
  SELECT NULL
),
categories_tmp AS (
  SELECT 'Electronics' AS category_name UNION ALL
  SELECT 'Peripherals' UNION ALL
  SELECT 'Mobile' UNION ALL
  SELECT 'Smartphone' UNION ALL
  SELECT NULL
)
-- 上記はサンプルデータです。以下のクエリを実行してください。
SELECT product_name FROM products_tmp
UNION
SELECT category_name FROM categories;
```

**実行結果:**

| product_name |
| :----------- |
| NULL         |
| Electronics  |
| Laptop       |
| Mobile       |
| Mouse        |
| Peripherals  |
| Smartphone   |


### 2. UNION ALL：和集合（重複を保持）

複数の`SELECT`文の結果を1つにまとめます。`UNION`とは異なり、**重複する行もそのまま全て表示**します。

重複チェックを行わない分、`UNION`よりも高速に動作する傾向があるため、重複を許容できる場合は`UNION ALL`の使用が推奨されます。

#### 基本構文

```sql
SELECT 列リスト FROM テーブル1
UNION ALL
SELECT 列リスト FROM テーブル2;
```

#### 具体例

`products_tmp`テーブルの商品名と`categories`テーブルのカテゴリ名をすべて表示します。`'Electronics'`と`'Smartphone'`は両方のテーブルに存在するため、結果では2行ずつ表示されます。

```sql
WITH products_tmp AS (
  SELECT 'Laptop' AS product_name UNION ALL
  SELECT 'Electronics' UNION ALL
  SELECT 'Mouse' UNION ALL
  SELECT 'Smartphone' UNION ALL
  SELECT NULL
),
categories_tmp AS (
  SELECT 'Electronics' AS category_name UNION ALL
  SELECT 'Peripherals' UNION ALL
  SELECT 'Mobile' UNION ALL
  SELECT 'Smartphone' UNION ALL
  SELECT NULL
)
-- 上記はサンプルデータです。以下のクエリを実行してください。
SELECT product_name FROM products_tmp
UNION ALL
SELECT category_name FROM categories_tmp;
```

**実行結果:**

| product_name |
| :----------- |
| Laptop       |
| Electronics  |
| Mouse        |
| Smartphone   |
| NULL         |
| Electronics  |
| Peripherals  |
| Mobile       |
| Smartphone   |
| NULL         |

### 3. INTERSECT：積集合（共通部分）

複数の`SELECT`文の結果の中で、**両方に共通して存在する行のみ**を返します。

#### 基本構文

```sql
SELECT 列リスト FROM テーブル1
INTERSECT
SELECT 列リスト FROM テーブル2;
```

#### 具体例

`products_tmp`テーブルと`categories`テーブルの両方に存在する名前のみを表示します。

```sql
WITH products_tmp AS (
  SELECT 'Laptop' AS product_name UNION ALL
  SELECT 'Electronics' UNION ALL
  SELECT 'Mouse' UNION ALL
  SELECT 'Smartphone' UNION ALL
  SELECT NULL
),
categories_tmp AS (
  SELECT 'Electronics' AS category_name UNION ALL
  SELECT 'Peripherals' UNION ALL
  SELECT 'Mobile' UNION ALL
  SELECT 'Smartphone' UNION ALL
  SELECT NULL
)
-- 上記はサンプルデータです。以下のクエリを実行してください。
SELECT product_name FROM products_tmp
INTERSECT
SELECT category_name FROM categories_tmp;
```

**実行結果:**

| product_name |
| :----------- |
| NULL         |
| Electronics  |
| Smartphone   |

### 4. EXCEPT / MINUS：差集合

最初の`SELECT`文の結果から、2番目の`SELECT`文の結果に**存在する行を取り除いた結果**を返します。
（DBMSによってキーワードが異なります）

*   **`EXCEPT`**: PostgreSQL, SQL Server, SQLite など
*   **`MINUS`**: Oracle

#### 基本構文

```sql
-- PostgreSQL / SQL Server
SELECT 列リスト FROM テーブル1
EXCEPT
SELECT 列リスト FROM テーブル2;

-- Oracle
SELECT 列リスト FROM テーブル1
MINUS
SELECT 列リスト FROM テーブル2;
```

#### 具体例 (`EXCEPT`)

`products_tmp`テーブルにのみ存在し、`categories`テーブルには存在しない名前を表示します。

```sql
WITH products_tmp AS (
  SELECT 'Laptop' AS product_name UNION ALL
  SELECT 'Electronics' UNION ALL
  SELECT 'Mouse' UNION ALL
  SELECT 'Smartphone' UNION ALL
  SELECT NULL
),
categories AS (
  SELECT 'Electronics' AS category_name UNION ALL
  SELECT 'Peripherals' UNION ALL
  SELECT 'Mobile' UNION ALL
  SELECT 'Smartphone' UNION ALL
  SELECT NULL
)
-- 上記はサンプルデータです。以下のクエリを実行してください。
SELECT product_name FROM products_tmp
EXCEPT
SELECT category_name FROM categories_tmp;
```

**実行結果:**

| product_name |
| :----------- |
| Laptop       |
| Mouse        |

### 5. まとめ：JOIN と 集合演算子の使い分け

| 項目 | JOIN (結合) | 集合演算子 (UNION, etc.) |
| :--- | :--- | :--- |
| **結合方向** | **横**（列が増える） | **縦**（行が増える） |
| **NULLの比較** | 結合されない（Unknown） | **一致とみなす** |
| **主な用途** | 属性の追加（名前と価格を紐付ける等） | データの統合・比較（過去と現在の比較等） |
| **計算負荷** | 結合キーのインデックスに依存 | 重複排除（ソート）による負荷が高い |

### 6.補足

#### パフォーマンスの最適化：UNION ALL と INTERSECT

集合演算子は便利ですが、内部で「重複排除（ソートやハッシュ処理）」を行うため、計算コストがかかる場合があります。

*   **原則：可能な限り `UNION ALL` を使う**
    `UNION`（ALLなし）は、全データを一度メモリ上に展開して重複をチェックします。重複がないことが分かっている場合や、重複しても問題ない場合は、チェック処理をスキップする `UNION ALL` を使うのが鉄則です。
*   **INTERSECT（積集合）の効率**
    一般的に、`INTERSECT` は `UNION` よりも高速に動作する傾向があります。
    *   `UNION`：すべての行をマージしてから重複を削る必要がある。
    *   `INTERSECT`：片方のテーブルにある値だけを調べればよいため、対象データが絞り込まれやすく、RDBMSの最適化（インデックスの利用など）が効きやすいためです。

#### 集合演算子の大きな特徴：NULL を「同じ」とみなす

JOIN（結合）と集合演算子の決定的な違いの一つが、**NULLの扱い**です。

*   **JOINの場合**: `ON t1.col = t2.col` では、`NULL = NULL` は `TRUE` にならず、結合されません。
*   **集合演算子の場合**: 2つのテーブルの同じ位置に `NULL` がある場合、それらを**「同一のデータ」**として扱います。
    *   `UNION`: 重複するNULLは1つにまとめられます。
    *   `INTERSECT`: 両方にNULLがあれば「共通データ」として抽出されます。

#### 実践テクニック：JOINによる集合演算の代用

MySQLのように `EXCEPT` や `INTERSECT` が未実装の環境や、より詳細な条件で絞り込みたい場合は、JOINを使って集合演算を再現します。

##### 例1：EXCEPT（差集合）を `LEFT JOIN` で再現
「AにあるがBにはない」データを抽出します。

```sql
SELECT p.product_name
FROM products AS p
LEFT JOIN categories AS c ON p.product_name = c.category_name
WHERE c.category_name IS NULL; -- 結合できなかった（Bになかった）行だけを残す
```

##### 例2：対称差（AとBのどちらか片方にしかない）を `FULL JOIN` で再現
「共通部分は除き、Aのみ、またはBのみに存在する行」を抽出します。

```sql
WITH
	customer_tokyo AS (
		SELECT
			*
		FROM
			customers
		WHERE
			city = 'Tokyo'
	),
	customer_osaka AS (
		SELECT
			*
		FROM
			customers
		WHERE
			city = 'Osaka'
	)

SELECT
	COALESCE(t.customer_id, o.customer_id) AS id,
	COALESCE(t.name, o.name) AS name
FROM
	customer_tokyo t
	FULL JOIN customer_osaka o ON t.customer_id = o.customer_id
WHERE
	t.customer_id IS NULL OR o.customer_id IS NULL;-- 共通部分（両方のIDがある行）を除外
```

#### 高度な応用：全称命題（すべて〜である）を解く
集合演算子は「否定」を表現するのが得意です。これを利用して、**「メンバー全員が〇〇であるチーム」**のような、集約関数（COUNT等）を使うと複雑になるクエリを簡潔に書けます。

```sql
WITH
	teams (member, team_id, status) AS (
		VALUES
			('ジョー', 1, '待機'),
			('ケン', 1, '出動中'),
			('ミック', 1, '待機'),
			('カレン', 2, '出動中'),
			('キース', 2, '休暇'),
			('ジャン', 3, '待機'),
			('ハート', 3, '待機'),
			('ディック', 3, '待機'),
			('ベス', 4, '待機'),
			('アレン', 5, '出動中'),
			('ロバート', 5, '休暇'),
			('ケーガン', 5, '待機')
	)

-- 全体集合
SELECT team_id
FROM teams

except

-- 待機じゃないメンバーがいる集合
SELECT team_id
FROM teams
where status <> '待機'
```
