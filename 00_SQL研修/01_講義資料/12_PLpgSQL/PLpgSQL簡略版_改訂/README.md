## この資料のコーディング規約

コード例はすべて次の規約で書かれています。演習の解答もこれに合わせてください。

| 対象 | 接頭辞 | 例 |
|:---|:---|:---|
| 変数 | `v_` (variable) | `v_customer_name` |
| 引数 | `p_` (parameter) | `p_customer_id` |
| 行データを入れる変数 | `r_` (record) | `r_product` |

接頭辞を付ける理由は [[12-1_PLpgSQLの基礎とDOブロック|12-1]] §5 で説明します。

- 匿名ブロックは `DO $$ ... $$;`（`LANGUAGE plpgsql` は省略）
- 関数は `CREATE OR REPLACE FUNCTION f(...) RETURNS <型> LANGUAGE plpgsql AS $$ ... $$;`
- プロシージャは `CREATE OR REPLACE PROCEDURE p(...) LANGUAGE plpgsql AS $$ ... $$;`
- 関数・プロシージャ名は小文字スネークケース
