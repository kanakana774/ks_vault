## 問題1:

「メールアドレスが登録されている顧客のメールアドレス」と
「レビューを書いた顧客のメールアドレス」を
重複は排除し、まとめて取得してください。

```SQL
SELECT
	email
FROM
	customers cu
WHERE
	email IS NOT NULL
UNION
SELECT
	cu.email
FROM
	reviews re
	INNER JOIN customers cu ON re.customer_id = cu.customer_id;
```
⇒ただ、これだと上半分だけで結果全量出ちゃうから問題の意図が分かりにくい問題になってますね、、、


## 問題2:
「商品レビューに投稿された日付」と「支払いが行われた日付」をまとめ、
すべての活動日一覧 を昇順で取得してください。

```SQL
SELECT
	review_date active_day
FROM
	reviews
UNION
SELECT
	payment_date active_day
FROM
	payments
ORDER BY
	active_day;
```

## 問題3:
商品名と、商品ごとの在庫数と注文数を同じ形式で結合したものを数(quantity)として取得してください。
またその際、それぞれの商品が在庫数か、注文数か、区別つけるため、sourceとして
在庫数の場合「Stock」、注文数の場合「Order」と表示するようにしましょう。
ただし、商品名ごとに表示されるように順番を指定してください。

```SQL
SELECT
	p.product_name,
	'Stock' AS source,
	SUM(i.stock_quantity) AS quantity
FROM
	inventory i
	INNER JOIN products p ON i.product_id = p.product_id
GROUP BY
	p.product_name
UNION ALL
SELECT
	p.product_name,
	'Order' AS source,
	SUM(oi.quantity) AS quantity
FROM
	orderitems oi
	INNER JOIN products p ON oi.product_id = p.product_id
GROUP BY
	p.product_name
ORDER BY
	product_name,
	source;
```


## 問題4:
「一度でも注文をした顧客」と「一度でもレビューを書いた顧客」の
両方に当てはまる顧客名を取得してください。

```SQL
SELECT
	c.name
FROM
	customers c
	INNER JOIN orders o ON c.customer_id = o.customer_id
INTERSECT
SELECT
	c.name
FROM
	customers c
	INNER JOIN reviews r ON c.customer_id = r.customer_id;
```

## 問題5:
「会員ランクを持つ顧客」から「一度も注文をしていない顧客」を除いた顧客名を取得してください。
⇒つまり、会員ランク持ちと注文経験客の共集合を取る
```SQL
SELECT
	c.name
FROM
	customers c
WHERE
	c.membership_id IS NOT NULL
intersect
SELECT
	c.name
FROM
	customers c
	INNER JOIN orders o ON c.customer_id = o.customer_id;
```
