### ステップ3：ベクトルDBの準備とデータの登録
次のセルに以下のコードを貼り付けて実行してください。
ここでは、日本語の文章をベクトル化してDBに保存します。

```python
import chromadb
from chromadb.utils import embedding_functions

# 1. ベクトルDBの初期化
client = chromadb.Client()
# 日本語に対応した無料のベクトル化モデル（Sentence-Transformer）を指定
# 384次元
emb_fn = embedding_functions.SentenceTransformerEmbeddingFunction(model_name="paraphrase-multilingual-MiniLM-L12-v2")

# 2. コレクション（テーブルのようなもの）の作成
collection = client.create_collection(name="my_collection", embedding_function=emb_fn)

# 3. データの登録（テキストデータ）
documents = [
    "美味しいラーメンが食べたい",
    "今日はとても天気が良くて気持ちいい",
    "最新のAI技術について勉強しています",
    "富士山に登って綺麗な景色を見たい",
    "プログラミング言語のPythonは人気があります"
]
ids = ["id1", "id2", "id3", "id4", "id5"]

collection.add(
    documents=documents,
    ids=ids
)

print("データの登録が完了しました！")
```

このコードは、ベクトルデータベースである ChromaDB を初期化し、日本語に対応したテキスト埋め込みモデルを設定して、指定されたドキュメントをデータベースのコレクションに登録する一連の処理を実行しています。

具体的には：

1. **ChromaDBの初期化**: `chromadb.Client()` を使用して、メモリ上に一時的なベクトルデータベースクライアントを作成しています。
2. **埋め込みモデルの設定**: `embedding_functions.SentenceTransformerEmbeddingFunction` を使って、日本語テキストを数値ベクトルに変換するためのモデル `paraphrase-multilingual-MiniLM-L12-v2` を指定しています。このモデルが、テキストの意味的な内容を数値で表現するために使われます。
3. **コレクションの作成**: `client.create_collection` で `test_collection` という名前のデータの入れ物（コレクション）を作成し、先ほど設定した埋め込み関数を関連付けています。
4. **データの登録**: `documents` リストにある日本語の文章と、それに対応する `ids` を指定して、`collection.add()` メソッドでコレクションにデータを追加しています。追加されたドキュメントは、指定された埋め込みモデルによって自動的にベクトル化され、データベースに保存されます。

### ステップ4：ベクトル検索を試す
いよいよ検索です。**「キーワードの一致」ではなく「意味の近さ」**で検索されることに注目してください。
例えば、「お腹が空いた」という言葉は登録していませんが、似た意味の文章がヒットします。

```python
# 検索したいキーワード
query_text = "何か食べたい"

# 検索の実行
results = collection.query(
    query_texts=[query_text],
    n_results=2  # 近い順に2つ取得
)

print(f"検索キーワード: {query_text}")
print("-" * 30)
for i in range(len(results['documents'][0])):
    print(f"結果 {i+1}: {results['documents'][0][i]} (距離: {results['distances'][0][i]:.4f})")
```

このコードは、定義された検索キーワードを使って、以前作成したChromaDBコレクションから関連性の高いドキュメントを検索し、その結果を表示しています。

具体的には：

1. **検索キーワードの設定**: `query_text` 変数に検索したい文字列「何か食べたい」を代入しています。
2. **検索の実行**: `collection.query()` メソッドを呼び出して検索を実行しています。
    - `query_texts=[query_text]` で、検索に使用するキーワードを指定しています。
    - `n_results=2` で、検索結果として最も類似度の高いドキュメントを2つ取得するように指定しています。
3. **結果の表示**: 取得した検索結果を整形して表示しています。
    - `results['documents'][0]` には検索によって見つかったドキュメントのリストが、`results['distances'][0]` にはそれぞれのドキュメントと検索キーワードとの距離（類似度が高いほど値が小さい）が含まれています。
    - `for` ループを使って、取得した各結果について、ドキュメントの内容と距離を分かりやすく出力しています。距離は小数点以下4桁で表示されています。


```
## 検索キーワード: 何か食べたい

結果 1: 美味しいラーメンが食べたい (距離: 0.2600)  
結果 2: 今日はとても天気が良くて気持ちいい (距離: 0.6748)
```

ChromaDBは、特に指定しない場合、近似近傍探索（HNSW）の指標として**「Squared L2（ユークリッド距離の2乗）」**を使用します。
- **L2距離（デフォルト）:** 0 に近いほど似ている（完全一致なら 0）。数値に上限はなく、離れれば離れるほど大きくなります。
- **今回の結果:** 「美味しいラーメン〜」との距離が **0.2600** というのは、かなり近い（似ている）という判定です。


## 2次元空間に落として視覚化

```python
import matplotlib.pyplot as plt
import japanize_matplotlib
from sklearn.decomposition import PCA
import numpy as np

# 1. まず「既存ドキュメント」だけで地図を作る
all_data = collection.get()
words = all_data['documents']
words_vectors = np.array(emb_fn(words)) # 既存データのベクトル

# PCAを「既存データ」だけで学習（Fit）させる
pca = PCA(n_components=2)
pca.fit(words_vectors) 

# 既存データの座標を確定させる
coords_words = pca.transform(words_vectors)

# 2. 検索キーワードを設定（ここを書き換えて何度も実行）
query_text = "富士山の天気" 
query_vec = np.array(emb_fn([query_text])) # 検索ワードのベクトル

# 確定した地図の軸（pca）を使って、検索ワードを座標変換する
coords_query = pca.transform(query_vec)

# 3. グラフ描画
plt.figure(figsize=(10, 7))

# 既存ドキュメントをプロット（青色・固定）
plt.scatter(coords_words[:, 0], coords_words[:, 1], color='blue', alpha=0.5, label="登録データ")
for i, word in enumerate(words):
    plt.annotate(word, (coords_words[i, 0], coords_words[i, 1]), alpha=0.7)

# 検索ワードをプロット（赤色の星・移動）
plt.scatter(coords_query[0, 0], coords_query[0, 1], color='red', s=200, marker='*', zorder=5, label="検索クエリ")
plt.annotate(f"★ {query_text}", (coords_query[0, 0], coords_query[0, 1]), color='red', fontweight='bold', fontsize=12)

plt.title(f"固定されたベクトル空間地図\n検索ワードの位置を確認")
plt.legend()
plt.grid(True, linestyle='--', alpha=0.5)
plt.show()
```


このコードは、ChromaDBに登録されたドキュメントと特定の検索キーワードをベクトル空間にマッピングし、その相対的な位置関係を可視化するものです。

具体的には、以下のステップを実行しています：

1. **必要なライブラリのインポート**: `matplotlib.pyplot` でグラフ描画、`japanize_matplotlib` で日本語表示対応、`sklearn.decomposition.PCA` で次元削減、`numpy` で数値計算の準備をしています。
2. **ChromaDBからドキュメントの取得**: `collection.get()` を使って、データベースに登録されている全てのドキュメント（テキストデータ）を取り出しています。
3. **検索キーワードの設定**: `query_text` に可視化したい検索キーワードを設定しています。
4. **全てのテキストのベクトル化**: 取得したドキュメントと検索キーワードを一つにまとめ（`target_texts`）、`emb_fn` (以前定義した埋め込み関数) を使って、これら全てのテキストを数値ベクトルに変換しています。これにより、ドキュメントと検索キーワードを同じベクトル空間に配置できます。
5. **PCAによる2次元への圧縮**: `sklearn.decomposition.PCA` を用いて、高次元のテキストベクトルを2次元に圧縮しています。これにより、ベクトル空間内の点の位置を2次元平面上にプロットできるようになります。PCAは、データのばらつきが最も大きくなる方向に軸を取り、情報を保持しながら次元を削減する手法です。
6. **グラフ描画**: `matplotlib` を使って、圧縮された2次元座標を散布図として表示しています。
    - ループで各ドキュメントと検索キーワードの座標 (`x`, `y`) を取得します。
    - 検索キーワード（「★検索」を含むもの）は赤色の大きな星マーク (`*`) で、強調して表示されます。
    - それ以外のドキュメントは青い点で表示されます。
    - それぞれの点には対応するテキストがアノテーション（ラベル）として付与され、点の距離が近いほど、そのテキスト同士の意味が類似していることを示しています。
    - グラフにはタイトル、軸ラベル、グリッドが追加され、視覚的に理解しやすくなっています。

この視覚化により、検索キーワードとどのドキュメントが意味的に近い位置にあるかを直感的に把握することができます。
