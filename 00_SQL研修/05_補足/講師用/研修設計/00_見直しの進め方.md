## 2. 設計方針

### 目的

研修の役割は二重。**中長期で伸びる土台**と、**配属直後の下限保証**。別物として設計し、別の定着を期待する。

### 二層構造

| | 本質軸（幹） | 暗記ハッチ |
|---|---|---|
| 目的 | 原理を理解する | 事故らない |
| 定着 | 導出できる | 覚える／見れば分かる |
| 評価 | 説明できるか | 漏れがないか |
| 陳腐化 | しない | する（それでよい） |

幹は削らない。ハッチは小さく明示する。

### 原則

1. **導けるものは導かせる。** 方法論は暗記対象ではなく答え合わせ。
2. **導けないが頻出するものは、暗記対象と明示して置く。** 両者を混ぜない。
3. **ハッチは網羅性で評価する。** 導出可能性は要件にしない。
4. **役割で切る。** 自分で直せる／気づいて報告する／知識として持つ。報告できることを軽視しない。
5. **移植可能性で取捨する。** 製品固有の名前は忘れてよく、原理は残る。どちらかを資料内で断る。
6. **先出し禁止。** まだ講義していない構文を課題で求めない。段階的に解禁する。

- **既存の完成品（`01_講義資料/`）は更新しない。新規ファイルを作る。** 改修は当面やらない

- **絶対値を覚えさせない。** 倍率と関係を本文、環境依存の実測値は折りたたみ
- **commit は自発的に**（`_base/02_協業ルール.md` §3）
- **禁止**: 完成品→詳細版のリンク／完成品に作業メモ／同じbasenameを2つ

## 4. 仕分け

### 幹（原理を説明し、導出を見せる）

NULLの三値論理／結合の原理（ON句とWHERE句、LEFT JOINを殺すINNER JOIN、行の増殖）／GROUP BYの論理実行順／集合の考え方（アンチジョイン3通り）／CASE式／サブクエリと相関／**書いたSQLを自分で検証する手順**／ウィンドウ関数／トランザクションと分離レベル／スキャン種別と結合アルゴリズム／手続き型で何を解決するか

### ハッチ2種

| 種類 | 誰に | 中身 |
|---|---|---|
| **(a) 導出できないゆえ** | 全員（暗記と明示） | 関数名／`ROUND(値,桁数)`は`numeric`のみ・`::numeric`／更新系の構文／カタログ名／psqlコマンド／**方言対応表**／`NULLS FIRST/LAST`／分離レベルの製品差／`Index Cond` と `Filter` |
| **(b) 習熟速度ゆえ** | 導出についてこれなかった人 | 幹の各項目に対する「このパターンを思い出して」 |

`NOT IN` のNULL罠は三値論理から**導出させる**（幹）。**同時にパターンとしても置く**（(b)）。

### 原則5で切る（製品固有の名前は忘れてよい）

| 移植可能（幹） | 固有（🐘） |
|---|---|
| スキャン種別・結合アルゴリズム・B-Tree・ページ | `EXPLAIN` 出力書式、`Bitmap Scan`・`Buffers`・`Heap Fetches` |
| 同時実行制御の原理、「先にログを書く」 | MVCC実装・`WAL` の呼び名 |
| 手続き型で何を解決するか（PL/SQL・T-SQLと概念共通） | PL/pgSQL構文 |
| **半開区間**（`>= 月初 AND < 翌月初`）、`TO_CHAR`（Oracleでもほぼ通る） | `date_trunc`（Oracleは `TRUNC(date,'MM')`） |
| `information_schema`（標準。Oracle/SQL Server/MySQLでも使える） | `pg_indexes`・`\d` 系 |
| **主キーとUNIQUEにはindexが自動で作られるが、外部キーには作られない**（Oracle・SQL Serverも同じ。**MySQL/InnoDBだけが例外**） | — |
| 倍率（約52倍・約247倍・約191倍・約1/400）、「Buffersが relpages と一致したら全件走査」 | `1,235ページ`・`7,255ページ` 等の環境固定値 |

### 原則4で切る（役割）

| 役割 | 範囲 |
|---|---|
| 自分で直せる | SELECT・結合・集約・サブクエリ・CASE・更新系＋検証手順 |
| 気づいて報告する | 遅いクエリ／ロック待ち／データ不整合／VACUUM・テーブル膨れ |
| 知識として持つ | パーティショニング・DWH・設定値チューニング |

根拠は「年次」ではなく**役割・権限**で書く（外部研修生は年次不定）。
