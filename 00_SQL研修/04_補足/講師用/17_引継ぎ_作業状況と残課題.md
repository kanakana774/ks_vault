## 15章で修正した「元資料の誤り」

旧 `15_トランザクションと排他制御.md` にあった誤りを、すべて実測で確認したうえで直しました。

| 箇所 | 誤っていた記述 | 実測で確認した正しい内容 |
| :--- | :--- | :--- |
| 分離レベル表 | Read Uncommitted で「ダーティリードが発生する」 | **PostgreSQL に Read Uncommitted は無い。** 指定は通る（`SHOW` は `read uncommitted` を返す）が、見えるのは確定済みの値だけ |
| 分離レベル表 | Repeatable Read で「ファントムリードが発生しうる」 | **PostgreSQL はファントムも防ぐ**（スナップショット固定）。SQL標準より強い |
| ロックのTIP | FK参照時は親行を自分で `FOR SHARE` する | **PostgreSQL が自動で `FOR KEY SHARE` を取っている。** 自分で書く必要はない |
| 用語 | 表は「独立性」、本文は「分離性」で不統一 | 「分離性（Isolation）」に統一 |
| 旧 `15_補足` | 「`EXCEPTION` ブロックの中では `COMMIT` できない」 | **不正確。** 禁止なのは `EXCEPTION` 句を持つブロックの**本体**。**ハンドラの中は通ってしまう**（が書くべきではない）→ 15-3 §3 |
| 旧 解答 問題1 | 問いに答えておらず、問題2の内容が書かれていた | 最終価格 1350.00 と、READ COMMITTED で読み直される理由を記述 |
| 旧 解答 問題2 | `EXCEPTION` ハンドラ内に `ROLLBACK;` | **削除。** 不要（書かなくても巻き戻る）かつ、トランザクション内で `CALL` すると `invalid transaction termination` で壊れる |

## 作業環境メモ

### 17章
- 実測用DB: `sql_lesson_execution_plan`（PostgreSQL 17.5、ローカル、`psql -U postgres -h localhost`、パスワードは `aevic`）
- 実測時は必ず `SET max_parallel_workers_per_gather = 0;` を先に実行すること（DB作成時に `ALTER DATABASE` で恒久設定済みのはずだが、新規接続で確認する癖をつける）

### 15章
- 検証には使い捨てDB `sql_lesson_tx` を作り、8章のDDL＋テストデータを投入して使った（**作業後に削除済み**）。再検証するなら [[08_結合から使用するテーブル]] の2つ目以降のSQLブロックをそのまま流せば同じ環境が作れる。
- **2窓シナリオの検証方法**：FIFOでpsqlを対話制御しようとすると Git Bash 上でハングする。**バックグラウンドのpsqlに `pg_sleep(n)` を挟んだヒアドキュメントを流し、前面のpsqlで `\timing on` して待ち時間を測る**のが確実。
- psqlの日本語メッセージがコンソールで文字化けするので、`PGCLIENTENCODING=UTF8` と `PGOPTIONS='-c lc_messages=C'` を付けると読みやすい。

### 共通
- SQLスクリプトは scratchpad（セッション終了で消える一時領域）に都度作成している。**再現用SQLは各Markdown内に埋め込んであるものが正。**
