## 残したもの（削らない）

- **手順とSQL** … 2窓シナリオの実行順は1つも省いていません
- **実測値** … 待ち時間・エラーメッセージ・出力はすべて同じ
- **表** … 判断に使う表（3分類・ロックモード・分離レベル・`state`）はそのまま
- **落とすべき一言** … 太字の結論は原則そのまま
- **🐘 の切り分け** … PostgreSQL 固有かどうかの注記

## 削ったもの

| 削ったもの | 例 |
| :--- | :--- |
| **同じことの言い換え** | 結論を段落で述べ直している箇所を1文に |
| **「なぜそう書くか」のメタな説明** | 「ここは実務でハマるポイントです」「ここが一番の誤解です」といった前置き |
| **導入の助走** | 各節の冒頭1〜2段落。表や手順から直接入る形に |
| **重複した伏線・回収の説明** | 「§2 で見たことがここで裏目に」を1回に |
| **例え話・背景説明** | WAL の狙い、MVCC の仕組みの詳しい言い回し |
| **深堀の Q&A** | 詳細版の `[!question]` ブロック（他DBとの比較など）。結論だけ 🐘 の一行にして完成品へ |
