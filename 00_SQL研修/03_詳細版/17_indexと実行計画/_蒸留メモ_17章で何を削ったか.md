## ⚠️ 15章のようには圧縮できていない（一番重要な記録）

15章は 40% / 55%（地の文は半分以下）まで落ちましたが、**17章は 67% / 87% / 90% で止まりました。** 理由は3つあり、**どれも「もっと削れたのに手を抜いた」ではなく、削る材料がなかった**ことによります。

1. **17章は 2026-08-07 に一度整理済みだった。** 旧 17-3（運用とチューニング）を `05_補足/講師用/講義の補足/17_運用とチューニング.md` へ移設し、**受講生に必要な分だけを再配置する**という作業をすでに通っています（→ `05_補足/講師用/17_引継ぎ_作業状況と残課題.md`）。15章にあった「助走・言い換え・設定値の話」の脂は、**そのとき既に落ちていました。**
2. **コードブロックの比率が高い。** 17-2 は全体の **40%**、17-3 は **46%** が SQL と `EXPLAIN` 出力です（17-1 は 25%）。15章の原則どおり**SQLと実測は1つも削っていない**ので、母数の4〜5割は最初から動きません。
3. **17章の地の文は「実測の読み解き」そのもの。** 15章の地の文は「なぜトランザクションが必要か」という**説明**が多く、削っても手順が残りました。17章の地の文は `Buffers: shared hit=1235` が何を意味するかの**解読**なので、削ると出力が読めない紙になります。

**次の章を蒸留するときは、圧縮率を目標にしないこと。** 15章の40%は「削れる脂があった章」の数字です。
