## 約束

- **更新はどちらからでもよいが、詳細版は完成品を内容として含む。**
  - **詳細版 → 完成品（蒸留）** … 既定の向き。深堀りしてから圧縮して落とす
  - **完成品 → 詳細版（還流）** … 完成品を直接直したら、詳細版に無い内容なら**ここにも書く**
  - **完成品にあって詳細版に無い記述は、同期漏れ。** 逆（詳細版にしかない）は正常
- 還流するときは**結論だけ貼らない。** ここは読み物なので、**根拠と経緯を付ける**。
- ファイル名は完成品と同名にせず **`_詳細` を付ける**（Obsidian のリンク解決が曖昧になるため）。
- **リンクは片方向。** 詳細版 → 完成品 は貼ってよい。**完成品 → 詳細版 は貼らない**（配布先でリンク切れになる）。
- 質問・深堀は `> [!question]-` の折りたたみブロックに置く。**結論だけ**完成品へ落とす。
- **削るのは「言い方」。「どこまで通じる話か」の切り分け（🐘 印）は削らない。**
- 章ごとに `_蒸留メモ_何を削ったか.md` を置き、残した／削った基準を記録する。

> 書き方・同期ルールの正本は vault 直下の `CLAUDE.md`。置き場の規約は `MyWork/_base/00_運用設計.md` §9.1(h)。
