## 約束（詳細は vault 直下の [[CLAUDE]]）

- **完成品が正本。** 詳細版は完成品の鏡ではないので、**ズレていて構いません**
- **同期は「逃がす」ときだけ。** 逃がす内容を対応する節に書き、**その節だけ**完成品と突き合わせる。
  他の節は見ない。定期点検も同期履歴の記録も要りません
- **蒸留（詳細版 → 完成品）は一度きり。** 繰り返すと完成品の作り込みが上書きで消えます
- 書き足すときは**結論だけ貼らない**。読み物なので**根拠と経緯を付ける**
- **逃がした内容は、講師の作業メモと混ぜない**（研修生に個別で見せるとき、混ざっていると見せられない）
- ファイル名は完成品と同名にせず **`_詳細` を付ける**（Obsidian のリンク解決が曖昧になるため）
- **リンクは片方向。** 詳細版 → 完成品 は貼ってよい。**完成品 → 詳細版 は貼らない**（配布先でリンク切れになる）
