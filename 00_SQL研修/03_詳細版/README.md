## 約束

- **完成品は詳細版から作る。逆は作らない。**
- ファイル名は完成品と同名にせず **`_詳細` を付ける**（Obsidian のリンク解決が曖昧になるため）。
- **リンクは片方向。** 詳細版 → 完成品 は貼ってよい。**完成品 → 詳細版 は貼らない**（配布先でリンク切れになる）。
- 質問・深堀は `> [!question]-` の折りたたみブロックに置く。**結論だけ**完成品へ落とす。
- **削るのは「言い方」。「どこまで通じる話か」の切り分け（🐘 印）は削らない。**
- 章ごとに `_蒸留メモ_何を削ったか.md` を置き、残した／削った基準を記録する。

> 正本は `MyWork/_base/00_運用設計.md` §9.1(h)。
