## 構成
- `01_講義資料/` … **配布する完成品。** `00_最初に/`・`12_PLpgSQL/`・`_attachments/`（画像）・`_excalidraw/`（図解用.excalidraw）
- `02_問題/` … `問題集_iTunes/`（総復習/時間が余った人用）・`問題集_実務想定/`
- `03_詳細版/` … **配布しない読み物。** 完成品はここから蒸留して作る → [[00_SQL研修/03_詳細版/README|03_詳細版]]
- `04_解答/` … 解答集（md・vault内参照用。原則⑦）

**番号は unit 内の並び順です。** 役割は名前で識別し、番号が他の unit と揃うとは限りません（この unit は `03_詳細版` を講義資料の隣に置くため、解答・補足を1つずつ後ろにずらしています）。
