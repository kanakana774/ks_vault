PostgreSQLのCLIツール（主に`psql`）を効率的に使いこなすための操作方法をカテゴリ別に整理したチートシートです。

---

### 1. 接続・終了操作（シェルから実行）
データベースサーバーへの接続に関するコマンドです。

| 操作                                    | コマンド                                                 |
| :------------------------------------ | :--------------------------------------------------- |
| <font color="#ff0000">**基本接続**</font> | `psql -U <ユーザー名> -d <DB名>`                           |
| **ホスト・ポート指定**                         | `psql -h <ホスト> -p <ポート> -U <ユーザー名> -d <DB名>`         |
| **URI形式で接続**                          | `psql postgresql://<ユーザー>:<パスワード>@<ホスト>:<ポート>/<DB名>` |
| **パスワード入力を強制**                        | `psql -U <ユーザー名> -W`                                 |
| **DB一覧を表示して終了**                       | `psql -l`                                            |
| **SQLを1つ実行して終了**                      | `psql -c "SELECT * FROM my_table;" -d <DB名>`         |

---

### 2. psql 内部での基本操作（メタコマンド）
`psql`にログインした状態で使用する、バックスラッシュ（`\`）から始まるコマンドです。

| 操作                                         | コマンド                     |
| :----------------------------------------- | :----------------------- |
| **ヘルプ表示**                                  | `\?`（psql用）、`\h`（SQL文法用） |
| **接続情報の表示**                                | `\conninfo`              |
| <font color="#ff0000">**DBを切り替える**</font>  | `\c <新しいDB名>`            |
| <font color="#ff0000">**psqlを終了する**</font> | `\q` または `Ctrl+D`        |
| **シェルコマンド実行**                              | `\! <コマンド>` (例: `\! ls`) |

---

### 3. オブジェクトの確認・一覧表示
DB内の構造を調査するためのコマンドです。末尾に `+` を付けるとより詳細な情報が表示されます（例: `\dt+`）。

| 表示対象                                       | コマンド         |
| :----------------------------------------- | :----------- |
| <font color="#ff0000">**データベース一覧**</font>  | `\l`         |
| <font color="#ff0000">**テーブル一覧**</font>    | `\dt`        |
| **ビュー一覧**                                  | `\dv`        |
| <font color="#ff0000">**テーブル定義の確認**</font> | `\d <テーブル名>` |
| **インデックス一覧**                               | `\di`        |
| **ユーザー（ロール）一覧**                            | `\du`        |
| **スキーマ一覧**                                 | `\dn`        |
| **関数一覧**                                   | `\df`        |

---

### 4. 表示設定・フォーマット
実行結果の見え方を調整します。

| 操作 | コマンド |
| :--- | :--- |
| **拡張表示（縦表示）** | `\x` （カラム数が多い場合に便利。on/off切り替え） |
| **実行時間の表示** | `\timing` （実行にかかったミリ秒を表示） |
| **NULLの表示文字列設定** | `\pset null 'NULL'` |
| **HTML/CSV形式出力** | `\pset format html` または `\pset format csv` |
| **ページャの無効化** | `\pset pager off` |

---

### 5. 外部ファイル・データ操作
ファイルの読み込みや、データのインポート/エクスポートに関する操作です。

| 操作 | コマンド |
| :--- | :--- |
| **SQLファイルを実行** | `\i <ファイルパス>` |
| **結果をファイルに出力** | `\o <ファイルパス>` （以降の結果が書き込まれる。戻すには `\o` のみ入力） |
| **CSVエクスポート** | `\copy (SELECT * FROM table) TO 'data.csv' WITH CSV HEADER;` |
| **CSVインポート** | `\copy table FROM 'data.csv' WITH CSV HEADER;` |
| **エディタでSQL編集** | `\e` （環境変数 `EDITOR` で設定したエディタが起動） |

---

### 6. バックアップ・リストア（シェルコマンド）
`psql`内部ではなく、OSのターミナルから直接実行するツールです。

| 操作 | コマンド |
| :--- | :--- |
| **DBバックアップ** | `pg_dump -U <ユーザー> <DB名> > backup.sql` |
| **特定のテーブルのみ** | `pg_dump -U <ユーザー> -t <テーブル名> <DB名> > table.sql` |
| **SQLファイルから復元** | `psql -U <ユーザー> -d <DB名> -f backup.sql` |
| **バイナリ形式で保存** | `pg_dump -Fc <DB名> > backup.dump` |
| **バイナリ形式から復元** | `pg_restore -U <ユーザー> -d <DB名> backup.dump` |

---

### 7. 便利な管理用クエリ（SQL）
よく使うシステム情報取得用のSQLです。

*   **バージョン確認:** `SELECT version();`
*   **現在の接続数を確認:** `SELECT count(*) FROM pg_stat_activity;`
*   **実行中の重いクエリを探す:**
    ```sql
    SELECT pid, now() - query_start AS duration, query 
    FROM pg_stat_activity 
    WHERE state = 'active' ORDER BY duration DESC;
    ```
*   **クエリの強制終了:** `SELECT pg_terminate_backend(<pid>);`
*   **テーブルサイズ確認:** `SELECT pg_size_pretty(pg_total_relation_size('<テーブル名>'));`
